# 任务建模与方法创新：协作机制调研

核验日期：2026-10-09。阅读了 `manuscript_draft_en.md` 与 `论文初稿文献核验.md`；范围为互补知识、隐蔽信息分布、通信与主动获取信息。只作理论研究；未修改论文、代码或 issues，未运行测试。以下建议是本项目的研究假设，不是既有论文已经证明的结论。AstroReview 的直接领域前作比较由主研究另行处理。

## 最值得保留的结论

**有价值的问题不是“专家怎样交流”，而是“哪些跨专业信息会改变、确认或限定方案可支持的知识，以及信息的影响应传播到哪里”。** 现稿已经有这个方向，但 Interfaces(M, F) 仍接近一个由协调者自由判断的黑箱。优先将它补成一个很小的行动协议：明确待解释的知识主张、它依赖而尚未弄清的前提、能够解释该前提的专业、收到证据后该主张的状态与适用范围。这里不要求消除未知，不要求意见改变，也不要求将所有研究改写成因果假设。

“独立研究→定向通信→综合”与“结构化消息、主动追问、有限轮次”已有近邻，不能单独作为创新。可争取的新意是**面向尚未实施研究的贡献依赖进行通信选择，并以知识主张的条件与影响范围作为协作的产物和验证对象**。是否成立，要用强基线和机制实验回答；本次有限检索不能支持“首次”。

## 五篇原始研究：机制、实证及边界

### 1. ExtAgents：已有基于相关性的信息汇聚与逐步判断可回答性

**精确书目**：Zijun Liu, Zhennan Wan, Peng Li, Ming Yan, Fei Huang, Yang Liu. 2026. *Scaling External Knowledge Input Beyond Context Windows of LLMs via Multi-Agent Collaboration*. Proceedings of ACL 2026, Volume 1: Long Papers, 10284–10314. DOI: 10.18653/v1/2026.acl-long.468。正式会议论文。[正式页面](https://aclanthology.org/2026.acl-long.468/)，[作者全文 §4–5](https://arxiv.org/html/2505.21471)。早期 arXiv 作者表另含 Ji Zhang，引用正式版本不要混用。

机制为分块 Seeking Agents、相关性排序的全局消息同步，以及 Reasoning Agent 按 top-2^s 逐步增加信息、检查可回答性。QA 与长综述实验优于所比方法；综述表5的 LLM 评分为7.63，对照6.75。表4“最佳配置”同时改变输入量，不能把其中差值视为等预算纯协作收益。

**对本项目**：信息相关性排序、渐进汇聚、发现信息不足都非新意；它处理给定材料上的问答/生成，未以“方案能够产生何种认识”的专业前提及影响范围组织通信。全文读取来自作者 arXiv 版本；ACL PDF 因体积限制未直接展开。

### 2. HiddenBench：不能把信息未浮现误判成整合推理失败

**精确书目**：Yuxuan Li, Aoi Naito, Hirokazu Shirado. 2026. *Systematic Failures in Collective Reasoning under Distributed Information in Multi-Agent LLMs*. Proceedings of ICML 2026, PMLR 306:69250–69268。正式会议论文。[正式页面](https://proceedings.mlr.press/v306/li26ej.html)，[全文 v4，§6.3–6.4](https://arxiv.org/html/2505.11556v4)。初版2025年；v4为2026-05-13。

65项任务、15个模型，分布信息组平均准确率30.1%，完整信息单体80.7%。18题诊断中，机械强制披露全部信息使 GPT-4.1/Gemini-2.5-Flash 达92.6%/98.2%，被动秘书汇总较弱。两轮各给1–2条决策事实及首选可能错的理由，再作决策，三模型均改善。

**对本项目**：角色不同不等于实际持有互补信息；先测关键事实有没有被取得、披露，再测收到后是否正确使用。强制披露与简单提示“请分享所有信息”是不同干预。该结果支持受控信息分布诊断，不证明真实跨学科评审的主要瓶颈必然相同。

### 3. Scaling Agent Systems：协作收益是任务结构与资源的条件命题

**精确书目**：Yubin Kim, Ken Gu, Chanwoo Park, Chunjong Park, Samuel Schmidgall, A. Ali Heydari, Yao Yan, Zhihan Zhang, Yuchen Zhuang, Yun Liu, Mark Malhotra, Paul Pu Liang, Hae Won Park, Yuzhe Yang, Xuhai Xu, Yilun Du, Shwetak Patel, Tim Althoff, Daniel McDuff, Xin Liu. *Towards a Science of Scaling Agent Systems*. arXiv:2512.08296v3，2026-04-08（初版2025-12-09）。[版本页面](https://arxiv.org/abs/2512.08296v3)，[全文 §4–5](https://arxiv.org/html/2512.08296v3)。本文所核验对象为预印本版本；[作者实验室](https://yang-ai-lab.github.io/)称2026年7月发表于 Nature Machine Intelligence，本次未核验到出版商文章及 DOI，故不补造正式刊载书目。

v3比较260配置、六基准、五架构、三模型家族；回归交叉验证 R²=.373（任务能力指标 .413），不是旧摘要中的180配置/.513。收益随可分解性、工具负担和单体能力而变。

**对本项目**：需纳入跨专业依赖很低的负对照，并给强单体相同材料与预算；不可把论文的约45%基线阈值当普适协作开关。其结果不能直接外推到科学申请评审。

### 4. PACT：已有“证据＋明确请求＋可用结果”的消息协议

**精确书目**：Chen Huang, Yuhao Wu, Wenxuan Zhang. 2026. *What Should Agents Say? Action-state Communication for Efficient Multi-Agent Systems*. arXiv:2606.05304v1，2026-06-03。所核验页面无正式刊载信息，按预印本处理。[原文 §3–6](https://arxiv.org/html/2606.05304v1)。

PACT把公开消息限制为 Action、State、Result，不改角色或轮次。两智能体分持多跳QA证据，另测顺序任务链和代码任务；消息保留接收者需要的事实与请求。HotpotQA消融中移除 Action，F1由69.9降至64.9。

**对本项目**：把“接口”落实成结构化字段仍不充分；缺失信息请求也已有前作。需要检验的额外内容是消息如何限定科学推断的有效条件，并使条件只影响相关贡献。PACT的QA正确性与代码任务效能不能当作专业推断有效性的证据。

### 5. Consilience：主动通信调度已有前作，统计保证不能照搬

**精确书目**：Abhijith Babu, Ramneet Kaur, Vishal Pramanik, Olivera Kotevska, Nathaniel D. Bastian, Susmit Jha, Sunny Raj, Yanzhao Wu, Sumit Kumar Jha, Anirban Roy. 2026. *Consilience: Conformally Calibrated Communication Control for Hidden-Profile Multi-Agent Reasoning*. arXiv:2608.20564v1，2026-08-20。预印本。[全文 §3–5及附录A](https://arxiv.org/html/2608.20564v1)。

用不确定性、分歧、证据增量、冗余等状态选择 challenge/clarify/seek-evidence/route；后两者路由给发言最少者。HiddenBench表1的 Qwen3-8B规则控制准确率.911，轮流讨论.149。保证针对固定程序、可交换校准分数下的逐轮代理损失后悔值，非最终决策正确率；计算需要从同一状态评估所有许可动作分支。

**对本项目**：不能把主动追问称首次，也不宜照搬全分支校准。其路由依据群体会话状态，我们可以研究依据科学贡献依赖选择问题与供方；两者是否有增益必须比较。该预印本只作最近机制参照。

## 现稿距离可检验方法还缺什么

1. **知识分工的对象**：目前 K_i 由专业调查自然产生，但未说明哪类前提必须依赖别的调查。不要人为隐藏原始申请来制造优势；保留共同访问权，区分“原文可见”“实际已获取”“已经用于某条推断”。
2. **通信触发规则**：不是出现两个专业词就建接口。候选接口应存在一个具体贡献解释，它至少有一个尚未查明的跨域前提；前提的合理取值会改变该解释的强度、适用范围或条件分支。无需双方先有分歧。
3. **接收后的科学动作**：专业答复后，由需要该前提的解释方说明：原判断得到确认、被限定、撤回，还是保留多个有价值的条件解释。协调者负责纳入共享模型；不能仅把两段回复拼接。
4. **通信价值的判据**：共享了多少新事实、说了多少轮、意见是否一致，都不能替代“是否支持正确的贡献解释”。价值可以是确认一个关键前提或准确保留未知，不应规定每次交流必须产生改判。

## 优先方向一：由知识主张所缺前提触发接口交流

**科学问题**：相同调查材料与预算下，围绕缺失的专业前提组织一次交换，能否减少跨专业推断中被默认为成立的条件？

**最小方法改动**：保留现有独立调查与有界交换，只增加一个简短接口记录：

| 内容 | 需要记录的实质 |
|---|---|
| 目标解释 | 哪个活动/观察预计支持哪种知识或能力 |
| 待解释前提 | 为什么现有专业认识还不能支持这一步；不是泛泛“不确定” |
| 请求与供方 | 对方需要给出的性质、尺度、适用条件或证据 |
| 共同解释 | 该前提如何支持或限制目标；仍未知时保留条件分支 |
| 作用范围 | 哪些贡献依赖这个前提，哪些不依赖 |

例：生物专家指出要区分的动态过程及其时间尺度；仪器专家说明真实采样/曝光条件可支持的观测尺度；共同解释回答哪些动态关系能辨别、哪些会混叠。这里的产物是解释边界，不是又一篇仪器报告，也不是强迫判定整个项目成败。

**真实候选新意**：将前瞻性项目中的“观察—认识—贡献”依赖变成协作任务本身。字段化、按需提问、专长路由是已知手段；新意若有，应落在任务对象与可证实的协作效果。

**可证伪预测**：

- 改善应集中在专家预先标注的跨专业依赖上；同样长、但知识不互补的案例不应有稳定收益。
- 给强单体或汇总者全部已获取关键事实后，收益若消失，说明主要贡献是信息披露/选择；若仍在，需要进一步检查是否来自推断表达或额外计算，不能直接声称“涌现”。
- 在离线评估中移除/替换关键专业前提，应只使依赖它的主张按预定方向变化；替换同长度无关消息不应有同等变化。不敏感表示没有使用信息，全面降级表示影响范围控制失败。这是科学实验，不是每次生产评审增加检查链。

## 可选方向二：按贡献敏感性分配最后一次调查

**科学问题**：调查预算有限时，问“哪项未知会改变方案能够支持的认识”是否优于追逐最大分歧、最高不确定性或最相关主题？

**低复杂度动作**：在已有候选接口中，为每个未决问题写两种合理回答，以及它们分别导致的贡献解释。若两种回答不改变任何重要解释，降低优先级；若改变关键贡献、且能由已知专业或检索任务澄清，优先调查一次。用“可调查、影响范围、任务重要性”作定性排序即可，不声称计算了精确期望信息价值，也不要求训练调度器。若答案必须等待未来实验，保留条件评价，不能无限检索。

**与现稿的实质差异**：现稿只说挑选 consequential interfaces；此处要求选择前先指出“答案不同会使哪项认识不同”，然后用固定预算验证这一选择是否有效。它是方向一的可选调度层，不宜两项都包装成独立大创新。

**可证伪预测**：在包含“高分歧但无关核心贡献”与“无分歧但缺重要前提”的配对案例中，这一规则应更常找到影响解释的证据；等量额外检索后贡献解释的专家评分增益应更大。若简单随机挑接口或按分歧排序达到同样效果，则该调度机制缺乏增益。

## 最小而有区分度的评估

保留现稿的强单体、独立调查后综合、完整方法比较；机制层新增两种必要对照：同样接口材料但只用通用 Action/State/Result 消息，以及同样材料全部汇集后直接综合。先固定证据池测试整合，再开放检索测试信息获取；两者不要混为一种能力。

让领域专家预先标注关键前提、支持关系和允许保留的条件分支。结果至少分别记录：关键证据取得率、进入共享解释的比例、跨专业推断有效性、无关贡献被错误降级的比例，以及包含检索和协调的总成本。以申请为统计单位，避免把同一申请中的许多主张当作独立样本。

这些设计足以检验一个收紧的主张：**适当的多智能体协作能够改善分布专业信息对前瞻性知识主张的使用，而非仅扩大报告、提高共识或压低不确定性。**
