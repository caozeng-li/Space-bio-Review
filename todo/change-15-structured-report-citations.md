# Change 15：从同一论述表示生成正文、来源和翻译

状态：已实施；离线交付及一个小节的真实翻译已验证。模型省略单元间换行的问题已由程序保留边界，并用原译文零 API 回放验证。依赖：[Change 14](D:/master/SpaceBioReview/demo_11/todo/change-14-statement-aware-synthesis-and-context.md)。

## 目标

让报告主文、支持条件、未决事项、附录、来源表和英文翻译消费同一份已接受的论述关系。消除“结构化归档正确，但交付又从任意字符串推导引用”的断点。

本项不重新评审，不用 writer 修复科学内容，不把全部报告改造成数据库或交互式网站，也不把来源数量下降当作内容质量证明。

## 当前实现的断点

- [Delivery.assemble](D:/master/SpaceBioReview/demo_11/src/spacebio_review/v4/delivery.py) 主要读取文本标记及块级集合，没有把 C 及局部支持关系作为最终组织依据。
- 来源身份由材料位置和 `material_version` 决定。同一篇文献的不同片段因而获得不同编号；mytest19 的 70 个编号只对应 23 个来源对象。
- [SourceScope.capture](D:/master/SpaceBioReview/demo_11/src/spacebio_review/reference_contract.py:63) 的 `material_version` 是实际阅读内容及阅读方式的摘要，不是整本文献的版本号。不能把它错误地当作文献级分组键。
- [translate](D:/master/SpaceBioReview/demo_11/src/spacebio_review/v4/delivery.py:391) 当前把带编号的整段文本交给模型；保存编号存在不等于保持每处局部对应关系。

## 统一交付表示

在现有 manifest 内保存按章节排列的论述选择和局部文本片段，记录 C 身份、局部条件、直接 E 和论证链接。沿袭与工作关联留在各自关系中，不混入材料来源列表。

- 主文、条件、替代方案、未知和请求说明采用相同的引用呈现接口。
- `text`、章节来源集合及 Markdown 是由结构生成的视图，不允许它们独立决定关系或回写权威内容。
- 专家原文附录保持原始意见的性质和版本；不能把综合改写替换成专家原话。
- 新 manifest 直接消费 C，旧 manifest/旧产物通过 Change 12 的显式适配路径渲染。无需重写已有运行目录。
- 只给本次实际引用的论述建立可访问落点；深层沿袭按链接追溯，不把全部祖先全文塞入主文。

## 来源编号与定位

区分机器内部的 E 身份和读者看到的来源编号：

1. 内部继续保留每份 E 的原文、阅读范围和冻结版本，不能以“同一论文”合并丢掉不同证据。
2. 显示层按已确认的同一来源对象分组，同一文献可共享编号并列出当前使用的具体定位。不同来源对象不按相似标题或作者自动合并。
3. 对相同位置的不同阅读快照保留差异，尤其不能把摘要证据显示成已经阅读全文。若材料版本确有差异，定位中予以区分，不假装是同一次观察。
4. 申请材料与外部文献在引用展示中能被识别；可使用统一编号加来源类型和定位，不必引入另一套会与 E/C/R 混淆的模型编号。
5. 正文某处仍绑定其精确 E。文献编号分组不能把同文献的其他片段再追加成当前证据。
6. 编号仅根据实际引用和确定的遍历规则生成；不依赖模型写数字。无需承诺跨不同报告永远保持同一个数字，但同一冻结 manifest 的编号应确定。

最终样式应能表达“同一文献，两个具体依据位置”，而不是用三个号码暗示三篇独立论文。合理的多文献支持仍全部保留，不设置每句编号上限。

## 推断与论证链接

直接材料依据与评审判断分开显示。对于新的条件性判断，可以先呈现必要事实和各自 E，再呈现明确标为推断的 C，并链接其前提论证。不得把前提 E 的传递闭包直接放在推断句后，冒充文献原结论。

镜像装置样例应能分别阅读：申请明确写了哪些用途；在已读范围内哪些设计仍未知；因此形成什么条件性建议。必要条件保留在正文，不通过折叠或附录移除来制造简洁。

## 翻译与摘要

### 翻译

- 模型输入是当前分片中有稳定 ID 的论述/文本单元，包含理解所需的相邻文字和局部范围。
- 返回翻译文字及其单元 ID，程序按原有关系装回 E、C/R 链接和来源编号。模型不生成或重排引用编号。
- 按现有批量大小组织多单元请求，不为每个 C、每个 part 单独调用模型。
- 分片不能拆开需要一起理解的主张和条件；局部语序调整在该绑定单元内完成。
- 这防止编号与归属由翻译重新决定，但不自动证明否定、条件和判断强度翻译正确；这些在小样本中人工核对。

### 摘要

本轮不扩展摘要任务为新的科学综合。给摘要的仍是已经接受的决定性结论、条件和真实覆盖，不附带全部证据档案；保留当前不生成文献编号的职责。摘要准确性不能冒充正文引用流转的验收结果。

## 开销

- 编号、链接、原位引用、重复来源分组和正文组装全部离线完成，不调用模型挑选“最好引用”。
- 翻译按固定批次进行，测量请求次数与总 token，不能以细粒度绑定为由产生逐句 API 调用。
- 新 manifest 保存关系后，重排、重新导出和改变显示编号无需重新综合或翻译。
- 不需要仅为改善引用而重新运行研究、检索或全篇报告写作。

## 验证

- 离线渲染完整覆盖三种关系：材料引用、推理前提链接、工作/沿袭链接；任何一种都不借编号伪装成另一种。
- 同文献不同片段共享显示编号时，当前语句仍只指向实际绑定的那些 E；摘要和全文片段可区分。
- 同一冻结 manifest 重复导出、正文重排和附录导出不制造不同的支持关系，且不调用模型。
- 用固定翻译响应验证语序变化后的装配，编号和关系不依赖返回字符串中的引用标记。
- 真实翻译仅使用 Change 16 的一个小节样例，核对条件、否定和局部归属，不翻译整份报告。

完成标准是显示清晰、关系不变、定位可追溯，并且渲染和重导出零模型调用。若只是把 70 个编号合并成较少编号，仍不能算完成。
