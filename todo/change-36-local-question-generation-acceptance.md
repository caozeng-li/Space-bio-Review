## 科学质量检查方式

人工检查完整生成题单，而不只看前 N 题；代码上限不能掩盖尾部重复。对每个输出分别记录：

1. **忠实性**：题目对象、实验阶段、条件与原计划书一致，没有把地面任务误设为在轨承诺。
2. **粒度**：不是全项目总论，也不是把参数、搜索动作、逐项 checklist 各拆一题。
3. **实质重合**：两题是否主要回答同一个判断、主要分析工作是否重复；共享证据或背景本身不算重合。
4. **责任清楚**：每题有一个已激活专家，职责可解释；跨学科不靠复制同题给多人解决。
5. **可开展分析**：不把缺未来实验结果等同于当前无事可做，也不要求现在完成未来实验。
6. **排序**：核心判断是否排在局部修饰问题之前，顺序是否偷偷按专家/章节组织；给出具体正反例，不要求跨次题号或全文一致。

对 A1-A3 特别逐项检查：成像能力是否又出现 q8/q12/q17/q19 式重复；地面成核与在轨观测是否区分；备选装置实施条件是否与成像判断边界清楚。对其他题同样按实质检查，不为了凑问题数挑措辞差异。

验收不通过的实质情形包括：重复承担同一核心判断、遗漏关键条件导致错误起题、把多数问题堆给明显不具备相关能力的专家、或把重要性排序退化成专家分组。修改点优先回到输入、职责或提示词，不添加出题后的语义补丁。

无需把三个输出变成完全相同的题目数；但严重粒度波动、明显重要问题消失必须披露。三次通过也只能说明这组局部样本通过，不能承诺所有未来输出绝对不重合。

## 真实输出的离线派工与恢复

每份完整真实输出都本地执行 N=1、3、10，以及大于实际题数的选择。核对原顺序、题号、唯一专家及完整条件；不再为不同 N 调用模型。

用真实 Coordinator 的局部准备/研究派发入口配合记录型 Research：

- 产生的正式研究任务数等于入选题数，没有合并、补题、重分配或多专家倍增。
- 截取项完整保留在原始批次，不进入研究调用，也不被标成科学上不适用。
- 再次恢复新增生成调用为零、已完成研究新增派发为零。
- 模拟专家返回科学局限，确认可进入综合输入视图而不会触发出题/路由。
- 单题模型上下文不携带其他题单、旧定位历史或累计请求链。

不使用完整 run_review 的真实流程做冒烟测试；默认 Runner 装配通过记录型供应商及局部调用验证。

## 开销比较

新路径只比较同一科学输入下的准备与出题部分：旧初始起题/定位/分配调用，与新的输入准备、一次全局出题及零模型派分。严格区分历史实测、本次实测和本地 token 估算。

记录完整序列化输入、schema、原文重复量、输出、思考额度、生成题数、入选题数和记录型研究任务数。实际派工数量由 N 稳定控制，不能把科学遗漏或模型失败造成的低用量当优化。

本轮复用冻结组队，不声称已实测整个新准备流程的总费用；可以用记录型调用序列证明不再调用专家定位，用请求预览说明上下文变化。不得推导完整评审节省率。

模型没有题数上限，完整题单生成自身仍有开销和输出容量风险。N 只限制后续研究规模，这一限制必须在结果中如实说明。
