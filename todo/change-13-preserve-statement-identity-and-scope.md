## 问题与目标

当前 [WorkingStatement](D:/master/SpaceBioReview/demo_11/src/spacebio_review/agents/types.py:14) 已有内容、范围、性质和身份，但 [归档读取](D:/master/SpaceBioReview/demo_11/src/spacebio_review/v4/records.py:125) 仍把 block 作为主要复用对象。[StatementBook.import_results](D:/master/SpaceBioReview/demo_11/src/spacebio_review/v4/statements.py:67) 再把整块注册为一条新的 `interpretation`。

离线实验已确认：一条外部事实和基于它的一条推断，经编译、归档、再导入后变成一条新 C。原始结构仍在 `statement_content`，但后续工作没有直接复用它。

本项使一份论述只有一份权威内容；原样复用不换身份，条件和直接证据不依赖模型重写才能保留。R 只组织论述，不能把文档容器的大小变成证据支持的粒度。

## 论述的粒度

C 表示可以独立复用、同时必须携带自身限定的一项认识，可以是申请自述、外部观察、推断、建议或未知。

- “在条件 A 下观察到 B”作为一个完整认识，不能拆成无条件 B 和可随意省略的 A。
- 不按字数或句号机械拆分。一个主张需要两项证据联合支持时，可以保留共同绑定。
- 不同对象、时点或性质的独立主张应分别组织，不能仅因为属于同一研究问题就全塞入一个 C。
- `parts` 用于局部文本和引用位置，不自行保证一个 part 是一个科学主张；论述组织在首次形成时完成。

## 字段职责

沿用现有结构，不新增通用事实数据库或大型证据关系枚举。

| 字段/对象 | 本轮职责 |
|---|---|
| `statement_id` | 程序拥有的不可变论述身份；原样导入保持不变 |
| `kind` | 保留申请、外部认识、推断、建议、未知的区别，不在导入时统一改为推断 |
| `parts[].cites` | 该局部文字的材料 E；新协议中不再混入整个 R |
| `scope` | 该 C 的适用条件、限制和保留；与 C 一起读取和交付，其引用不并入正文其他位置 |
| `premise_ids`，计划新增 | 当前推断实际依赖的 C；不是自动继承文献编号的指令 |
| `based_on` | 收窄为内容沿袭或导入来源，仅作追溯，不再同时表示推理前提 |
| `supersedes` | 修订替代关系，旧版本仍可追溯，但不作为当前结论再次交付 |
| R 的块组织 | 保存被选择的 C 和顺序；文本、块级 E/R 并集由程序派生 |

支持、反证和条件的作用首先通过对应论述内容、`kind` 和现有工作分组保留，不要求模型为每个来源再填一串抽象评分。事实来自申请，不代表事实已被外部验证；推断有前提，也不代表原始论文直接给出了该推断。

### 身份与版本

继续由程序计算身份，模型只选任务内别名。新 schema 的身份计算包含正文、局部范围、性质和支持关系，别名和报告顺序不参与；内容或条件修改产生新身份。作者、导入路径等沿袭信息由档案保存，不能仅因换任务、换别名或重新分组就制造新的科学论述。

已有身份算法与新表示可能不同，必须明确版本适配：旧结构化档案中的身份作为冻结旧版本身份保留，不能按新字段默认值重新散列后冒充原对象。需要改写或拆分时建立新 C，并记录旧 C/R 的来源关系。

## 权威表示与读取接口

扩展现有 `StatementBook`、`Records` 和 `TaskContext`，让它们共同维护一个权威论述注册表及块的选择关系。可以沿用并版本化 `statement_content`，但不能再同时独立维护第二份可变的 statement 表和任意正文。

- 保存时记录实际选中的 C、其必要前提、局部条件和版本关系；工作档案可以完整，提示词视图不因此必须完整展开。
- 读取结构化产物时直接恢复原 C。`statement_origins` 不能只是展示标签；完整内容应能通过相同身份取得。
- 普通调用方只需选择/读取论述、获取当前任务视图、编译产物。谱系遍历、别名转换和旧格式适配集中在该模块内，不散落到综合、路由和交付中。
- 编译块不默认复制所有前提和祖先全文。当前判断需要的前提可显式安排呈现，沿袭链只保留链接；当前 C 的必要限定不能被省略。
- 不依据 `based_on` 把已修订结论或全部历史分支重新放回工作集。

## 旧产物适配

分三种情况处理，不把不存在的信息补造出来：

1. 有完整 `statement_content`：保留 C 身份和局部结构；旧 `based_on` 缺少明确语义的关系作为旧版沿袭关系保存，不猜测它是否是逻辑前提。
2. 只有 `citation_content`：保留局部文字和 E/R 绑定，但标明其还是旧版论述片段。R 保持论证链接，不能通过其祖先集合生成直接 E。
3. 只有文本和集合：按 Change 12 作为不透明旧论述读取。不得把自动切分的句子标成已核实的新 C。

在确实需要细化旧论述时，后续局部综合可以读取原文、主动形成新 C，并留下来源关系。这是新的认识工作，不是导入时偷偷做的语义迁移。

## 上下文与开销

- 同一 C 在单次任务视图中只出现一份，其他位置使用别名；共同范围可内部去重，但读取 C 时必须同时拿到范围。
- 当前工作集包含被选 C、必要前提及已保留的相关反证/未知，不把全部历史版本和原文快照常驻提示词。
- 直接引用的 E 仍可回读；已经形成的 C 复用时，不要求再发送整篇原文或再次生成一句摘要。
- 提示词容量计算使用实际任务投影，不使用档案总大小代替。
