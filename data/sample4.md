# 一、摘要（约 500 字）

# 1、研究内容、意义、在空间站开展的必要性；

太空微重力条件易引发机体糖代谢相关疾病，亟需适用于太空用药的高效和长效治疗手段。核酸药物在代谢性疾病治疗方面显现了高效和长效作用的前景，有望成为重要的太空治疗策略，皮下注射一针就可以实现 6-12 个月的显著疗效。

在核酸药物治疗及应用中，脂质纳米载体发挥了至关重要的作用，它可高效克服细胞膜屏障到达胞内靶位，实现高效递送核酸药物并发挥治疗效果的作用。但是，在微重力环境中，载体受重力影响产生的沉降效应消失，载体与细胞相互作用的生物力学规律可能与地面重力环境下显著不同。因此，在微重力条件下开展核酸药物研究，探究脂质纳米载体与细胞相互作用的影响和规律，以及靶位释放的机制，有助于合理设计高成药性的核酸药物载体，对于太空用药及保障航天员健康具有重要意义。

本项目聚焦空间站科学实验研究方向——空间生命科学与生物技术，拟探究微重力条件对药物荷载、胞内递送，以及 “中心法则”的影响；从而阐明微重力条件下核酸药物递送的规律和机制，进而探究新型糖代谢疾病治疗手段。在前期已完成核酸脂质纳米载体制备的基础上，进一步开展微重力环境下，核酸脂质纳米载体克服入胞屏障、胞内转运、以及靶位释放等的研究。

该项目的顺利实施可为未来空间制药技术开发面临的共性科学问题提供早期解决策略，并为开发地面重大疾病的新型治疗方法提供解决方案。

# 2、预期成果。

本项目拟阐明微重力条件下核酸脂质纳米载体克服入胞及胞内转运屏障的影响和规律，揭示微重力条件下核酸脂质纳米载体靶位释放的规律和微观结构变化机制，并提供一种糖代谢相关疾病的新型潜在治疗手段。同时，发表 SCI 论文 1-2 篇。

# 2、主要研究内容；

本项目聚焦空间站科学实验研究方向——空间生命科学与生物技术，在前期已完成的核酸脂质纳米载体制备基础上，进一步开展微重力环境下，核酸脂质纳米载体克服入胞屏障、胞内转运以及靶位释放等方面的研究，可为高效精准递送的核酸脂质纳米载体的理性化设计提供新的理论指导，进一步提供一种新型糖代谢疾病的潜在治疗手段。

$\textcircled{1}$ 基于空间微流控芯片技术制备核酸脂质纳米载体

以PCSK9 siRNA为模型药物，利用空间微流控芯片技术，通过调节脂质和核酸药物分子的不同浓度、比例以及灌流速率，得到核酸脂质纳米载体。随后对载体进行粒

径、分布、电位、形貌、载药量及包封率进行考察；并在模拟空间微重力环境下，检测药物释放速率，对载体及荷载药物的稳定性进行考察。

# $\textcircled{2}$ 微重力条件下核酸脂质纳米载体克服入胞屏障的研究

通过三维旋转仪培养细胞模拟地面微重力，以LO2细胞作为模型，考察载体的细胞摄取情况和入胞机制，探究微重力对核酸脂质纳米载体入胞效率、入胞机制的影响。

# $\textcircled{3}$ 微重力条件下，核酸脂质纳米载体胞内输运的研究

通过三维旋转仪培养细胞模拟地面微重力，观察载体与不同细胞器的共定位情况及其在细胞器的转运过程，进而探究微重力对核酸脂质纳米载体胞内运动、亚细胞器转运的影响。

# $\textcircled{4}$ 微重力条件下，核酸脂质纳米载体胞内靶位释放的研究

通过三维旋转仪培养细胞模拟地面微重力，考察载体与靶细胞器的共定位情况。同时，观察载体在细胞内释放药物的情况，探究微重力对核酸脂质纳米载体在内质网等靶位释放的影响。进一步，利用RT-qPCR实验及Western Blot实验考察基因沉默效率PCSK9蛋白在细胞内的表达量。

# ⑤在轨实验及返回实验方案

首先，根据地面实验结果迭代计算出微重力条件下适宜的核酸脂质纳米载体浓度、

孵育实验等实验参数，确定微重力条件下核酸脂质纳米载体入胞、胞内转运和靶位释放的可能规律和机制。进一步，完善和明确在轨实验运控方案，力争进行在轨实验验证，为真正的实现太空飞行中的健康保障提供参考。

1） 本项目首次提出利用空间微流控技术制备脂质纳米颗粒用于递送核酸药物，可获得载药量高、粒径分布均一的核酸脂质纳米载体。  
2） 本项目首次在微重力条件下，观测脂质纳米载体克服胞内转运屏障的微观机制及其胞内释药过程，可为核酸药物载体的理性化设计提供新的理论指导。

# $\textcircled{1}$ 基于空间微流控芯片技术制备核酸脂质纳米载体

（A）核酸脂质纳米载体的制备：以PCSK9 siRNA为模型药物，利用空间微流控芯片技术，在左侧通道注入核酸水溶液，在右侧通道注入脂质溶液，通过调节脂质和核酸药物分子的不同浓度、比例以及灌流速率，得到核酸脂质纳米载体。（B）粒径、电位以及形态的考察：将样品以去离子水稀释，分别置于Zetasizer Nano ZS粒度仪的粒径池和电位池中，于室温下测定样品的平均粒径和电位，每个样品各测定三次。取 600μL外泌体溶液，经2%磷钨酸负染后使用透射电子显微镜于 $1 2 0 \mathrm { k V }$ 下进行形态学观察及拍照。（C）载药量测定：取适量核酸脂质纳米载体于超速离心管内，配平后于 4$^ { \circ } \mathrm { C }$ ，100000 g条件下离心60 min。取上清于石英底96孔板中，用酶标仪进行荧光定量，计算出体系游离核酸的质量W游离。按照公式 $( \mathsf { W } _ {  } - \mathsf { W } _ { \ast \frac { \partial \pm \pi } { \partial \Psi } } ) / ( \mathsf { W } _ {  } - \mathsf { W } _ { \ast \frac { \partial \pm \pi } { \partial \Psi } + \mathsf { W } _ { \ast \frac { \partial \pm \theta } { \partial \Psi } } + \mathsf { W } _ { \ast \frac { \partial \pm \pi } { \partial \Psi } } + 1 } ) \times 1 0 0 \%$ 进行载药量的计算，按照公式(W 总-W 游离)/W 总×100%进行包封率的计算，其中 W 总为载药前体系中加入的核酸药物总质量， $\textrm { W } _ { \# \ell \mathrm { f } \ell }$ 为体系中载体的质量。（D）药物释放速率检测：在模拟空间微重力环境下，以 $\mathrm { p H } 7 . 4$ 的PBS作为释放介质，于对应时间点取出5 mL释

放介质并以空白释放介质补足。利用酶标仪进行荧光量检测，对比标准曲线计算总核

体溶液，测定其粒径、电位、载药量，以此考察其在一个月内的稳定性。

# $\textcircled{2}$ 微重力条件下核酸脂质纳米载体克服入胞屏障的研究

（A）微重力条件模拟：通过三维旋转仪培养细胞模拟地面微重力，即通过使细胞

各个表面均等地受到重力作用从而通过矢量和为零达到对于微重力的模拟。（B）细胞

摄取定量实验：在三维旋转仪中培养 LO2细胞作为模型，加入载荧光标记核酸的脂质

纳米载体孵育2 h。结束孵育后， $2 0 0 0 \mathrm { r p m }$ 离心 3 min。弃去培养基后用 1 mL PBS 复悬

细胞，重复以上操作三次后利用流式细胞仪考察胞内的核酸总量，评价核酸脂质纳米

载体的细胞摄取效果。（C）入胞机制考察：加入含有不同内吞抑制剂（氯丙嗪、制霉

菌素、阿米洛利和甲基-β-环糊精）的HBSS溶液培养箱孵育 $0 . 5 \mathrm { h }$ ，然后每孔加入荧光

标记的载体孵育2 h。同时设置空白对照 别在 $3 7 ~ ^ { \circ } \mathrm { C }$ 和 $4 ^ { \circ } \mathrm { C }$ 条件下孵育。结束孵育

后， $2 0 0 0 \mathrm { r p m }$ 离心 3 min。弃去培养基后用 1 mL PBS 复悬细胞，重复以上操作三次后

使用流式细胞仪进行细胞摄取量考察，进而确定细胞摄取机制。进一步探究微重力对核酸脂质纳米载体入胞效率、入胞机制的影响。

# $\textcircled{3}$ 微重力条件下，核酸脂质纳米载体胞内输运的研究

通过三维旋转仪培养细胞模拟地面微重力，对载体进行荧光标记后，将其与LO2细胞共培养共培养结束2 h后，采用活细胞器染料对内涵体、溶酶体、内质网和高尔基体进行荧光标记，对载体在细胞器的转运过程进行实时观察。此外，利用免疫荧光染色方法分别标记各个细胞器，并通过超分辨率显微镜观察载体与各个细胞器的共定位情况。

# ④微重力条件下，核酸脂质纳米载体胞内靶位释放的研究

（A）内质网靶位释放的考察：通过三维旋转仪培养细胞模拟地面微重力，分别用特异性一抗和二抗标记细胞的内质网等靶位，采用激光共聚焦显微镜及超分辨率显微镜等技术考察载体与靶细胞器的共定位情况。为定量观察载体在细胞内释放药物的情况，将细胞与负载荧光标记的核酸的脂质纳米载体共同孵育；孵育 $2 4 \mathrm { { h } }$ 后，按上述方法裂解收集胞浆馏分，用酶标仪测定其荧光含量，进而探究微重力对核酸脂质纳米载体在内质网等靶位释放的影响。（B）靶向PCSK9的siRNA的基因沉默效率的研究：

主要从mRNA水平及蛋白表达水平两方面进行评价，具体操作如下：通过三维旋转仪培养细胞模拟地面微重力，待LO2细胞生长至 $6 0 \% - 7 0 \%$ 融合度时进行细胞给药。考察mRNA 水平的基因沉默效率时，于孵育 $2 4 \mathrm { { h } }$ 后使用胰酶消化细胞，提取总 RNA，测定RNA浓度后，使用cDNA合成试剂盒进行反转录实验。最后通过 RT-PCR检测各实验PCSK9 mRNA 水平，PCSK9 的引物序列：上游 $5 ^ { \prime }$ 组-ACGATGCCTGCCTCTACTCC-3′，下游 5′- GCCTGTGATGTCCCACTCTGT-3′，PCR 扩增产物长度为 205bp；GAPDH的 引 物 序 列 ： 上 游 5′-TCACCATCTTCCAGGAGCGAG-3′ ， 下 游 5′-TGTCGCTGTTGAAGTCAGAG-3′，PCR 扩增产物长度为 697 bp。考察蛋白表达水平时各实验 孵育 $2 4 \mathrm { { h } }$ 组后，使用 RIPA 蛋白裂解液对细胞进行裂解，于冰上操作，经蛋白免疫印记实验检测各实验 处理后，LO2细胞的PCSK9蛋白表达水平。

# $\textcircled{5}$ 在轨实验及返回实验方案

在地面模拟研究中，利用大样本量和多次重复实验，确定微重力条件下核酸脂质纳米载体入胞、胞内转运和靶位释放的可能规律和机制。同时，迭代计算出微重力条件下适宜的核酸脂质纳米载体浓度、孵育实验等实验参数，完善和明确在轨实验运控方案。

# 六、项目风险分析与控制

项目牵头单位与项目参与单位已经开展了深入合作，在本项目所涉及的各个研究内容均具备一定的技术储备。前期研究中，项目 已成功开发空间微流控芯片药物微

胶囊制备技术，实现模拟微重力条件下脂质纳米载体的制备，充分证实了本项目技术方案的可行性和优越性。

此外，在轨实验中如何保障细胞在空间飞行中的良好生长状态是关系实验成败的重要因素，同时也具有一定的不确定性。空间细胞培养的不确定性主要来自航天过程的若干不可控因素，如出发前和发射过程中可能的较长时间非 $3 7 \mathrm { { ^ \circ C } }$ 无 $\mathrm { C O } _ { 2 }$ 状态、发射时的剧烈震动等等，这些情况可能影响细胞的生长状态。针对这种不确定性因素，项目 将进行大量的发射条件模拟，针对 $1 0 { - } 3 7 ^ { \circ } \mathrm { C }$ 组的不同温度范围和时间区段进行各种培养细胞的生长曲线绘制，并进行重复验证。以保证可以有针对性地对细胞准备制定发射前细胞培养地起始浓度。

综上，项目 充分考虑了全部研究内容的可能风险和不确定因素，并针对这些内容考虑了相应措施，以避免技术延误或造成阻滞。研究团队已经对可能的风险因素进行了认真评估，并指定了对应计划和措施。因此，本项目整体分析立项充分，无明显重大风险，研究计划高度可行。
