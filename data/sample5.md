# 一、摘要（约 500 字）

# 1、研究内容、意义、在空间飞行环境中开展的必要性；

重力是地球生命发育过程中持续存在的环境因子。出生后早期的运动系统、前庭系统、脊髓反射回路和骨骼肌控制能力都在重力负荷、姿势维持和自主运动训练中逐步成熟。若在出生后关键发育窗口内长期暴露于微重力环境，动物的姿势控制、步态协调、肌肉反射、前庭-运动整合以及神经肌肉连接可能发生适应或发育偏移。理解这些变化不仅有助于评估未来长期空间居住中哺乳动物发育和生殖相关风险，也可为儿童运动发育障碍、前庭功能异常和神经肌肉可塑性研究提供参照。

本项目基于 NASA Neurolab / STS-90 任务中的啮齿类动物发育实验，拟研究微重力暴露对出生后大鼠运动能力发育的影响。研究对象为出生后早期大鼠幼崽，在飞行期间通过专用 Animal Walking Apparatus（AWA）记录其在不同表面上的自主行走、抓握、翻正和姿势控制表现，并在返回地面后继续开展步态、游泳、翻正反射、惊跳反射和组织学分析。项目重点考察：微重力是否会延迟或改变正常运动行为发育；飞行后这些变化是否可恢复；不同出生后发育阶段对微重力的敏感性是否不同；行为改变是否伴随脊髓运动神经元、脑皮层和感觉运动通路结构变化。

在空间飞行中开展本研究具有必要性。地面悬吊、旋转或前庭干扰模型只能模拟局部卸载或异常感觉输入，无法同时重现全身微重力、飞行振动、密闭环境、昼夜节律改变和动物在轨自主活动条件。真实空间飞行可直接观察幼年哺乳动物在无持续重力负荷条件下如何学习和维持运动行为，是验证重力对出生后运动发育作用的关键实验场景。

# 2、预期成果。

本项目预期获得以下成果：1）形成出生后早期大鼠在空间飞行期间运动行为发育的连续视频和行为评分数据；2）比较飞行组、同步地面对照组和普通饲养对照组在步态、翻正、游泳和惊跳反射上的差异；3）获得微重力暴露后脊髓运动神经元、脑皮层和肌肉相关组织的形态学数据；4）确定出生后不同发育阶段对微重力暴露的敏感窗口；5）建立可用于后续空间发育生物学研究的啮齿类幼体行为测试和组织分析流程。

# 二、主要指标

# 1、项目总目标（要求目标清晰可考核）；

（1）评估出生后早期大鼠在微重力环境中的自主运动发育过程，包括行走、抓握、姿势维持和翻正能力。

（2）比较不同发育阶段幼鼠对空间飞行暴露的敏感性，重点考察 P8-P24 与 P14-P30 等出生后阶段的运动行为差异。

（3）判断飞行后运动行为改变是否持续存在，以及返回 1g 环境后是否出现恢复或过度补偿。

（4）分析行为改变与脊髓运动神经元、脑皮层突触连接、前庭-运动通路和骨骼肌状态之间的关系。

（5）验证 Animal Walking Apparatus 在轨记录幼鼠运动行为的可行性和数据质量。

# 3、预期成果与水平。

（1）科学成果：明确出生后早期大鼠在微重力暴露下是否出现运动发育延迟、步态异常、翻正反射改变或游泳行为异常，揭示重力输入在出生后运动系统成熟中的作用。

（2）方法成果：建立用于空间飞行幼鼠运动行为观察的 AWA 测试流程、视频评分方法和返地后行为学验证方案。

（3）机制成果：获得与运动行为改变相关的脊髓、脑皮层和肌肉组织形态学数据，为解释微重力对神经肌肉发育的作用提供基础。

（4）应用成果：为长期空间居住、空间生殖和发育风险评估提供动物实验依据，也为地面运动发育障碍和前庭-运动适应研究提供模型参考。

# 三、主要研究内容

# 1、拟重点解决的科学问题或关键技术；

# 关键科学问题：

1）出生后早期哺乳动物运动行为是否需要持续的 1g 重力输入才能正常成熟？

2）微重力暴露对幼鼠行走、抓握、姿势维持、翻正和游泳行为的影响是否具有日龄窗口差异？

3）空间飞行导致的运动行为改变在返回地面后是快速恢复、持续存在，还是出现补偿性改变？

4）行为改变是否与脊髓运动神经元树突发育、脑皮层运动区突触结构或肌肉状态变化相关？

5）在轨视频行为数据能否稳定捕捉幼鼠运动发育过程，并与返地行为测试形成相互验证？

# 关键技术问题：

1）幼鼠在飞行任务中的饲养、母幼同笼管理和健康维持；

2）在微重力环境中稳定诱导幼鼠通过不同测试表面，并获得可评分视频；

3）飞行组与地面对照组在温度、湿度、照明、笼具、饲养节律和人为操作上的一致性；

4）返地后急性行为测试的时间窗口控制，避免恢复过程掩盖飞行效应；

5）行为学指标与组织学指标之间的对应关系建立。

# 2、主要研究内容；

本项目包括以下四部分研究内容。

（1）幼鼠空间飞行运动行为记录。使用出生后早期大鼠幼崽作为研究对象，将飞行组安排在 Neurolab 任务期间进入空间飞行环境。飞行期间定期将幼鼠置于 Animal Walking Apparatus 内，记录其在不同直径水平杆、网格表面和泡沫表面上的运动表现。重点指标包括：主动移动距离、通过测试面的时间、前后肢协调、抓握失败次数、失足次数、姿势稳定性、翻正能力和运动探索行为。

（2）不同发育阶段敏感性比较。根据出生后日龄设置至少两个发育窗口：较早阶段暴露组用于观察微重力对初始运动学习和姿势控制建立的影响；较晚阶段暴露组用于观察微重力对已开始形成的步态和神经肌肉控制的影响。通过比较不同日龄组的飞行行为数据和返地行为数据，判断发育窗口敏感性。

（3）返回地面后的行为学验证。飞行动物返回后，在尽可能短的时间内进行地面测试，包括水平杆行走、开放场活动、游泳测试、表面翻正反射、空中翻正反射和听觉惊跳反射。通过这些测试判断在轨观察到的运动差异是否在 1g 环境中持续存在，并评估前庭、脊髓和肌肉控制相关功能。

（4）神经肌肉组织学分析。对飞行组和对照组动物采集脊髓、脑皮层、骨骼肌和必要的前庭相关组织。脊髓分析重点关注运动神经元形态、树突分支和突触输入；脑组织分析关注运动皮层和感觉运动整合区域的细胞结构；肌肉分析关注肌纤维大小、肌肉成熟标志物和可能的卸载适应变化。组织结果与行为学数据进行关联分析。

# 3、研究中的创新点。

（1）本项目关注出生后发育阶段，而不是成年动物短期卸载反应，可直接回答重力环境是否参与运动系统成熟这一基础问题。

（2）项目在真实微重力环境下连续观察幼鼠运动行为，能够避免地面模拟模型无法完全再现空间飞行环境的问题。

（3）项目将飞行中视频行为记录、返地后功能测试和神经肌肉组织形态学分析结合，可从行为和结构两个层次解释微重力效应。

（4）项目设置不同出生后日龄窗口，有助于识别空间飞行暴露对运动发育的敏感阶段。

# 四、研究方案

主要采用的研究方法和技术方案，包括地面研究/研制方案、在轨实验方案。

# 1、实验对象与分组

实验动物为实验室大鼠幼崽，飞行前按出生后日龄、体重、窝别和健康状态进行分层分组。每个飞行组设置相应的同步地面对照组，地面对照组使用相同或等效笼具、饲养程序、光照节律和测试时间安排。另设普通饲养对照组，用于区分飞行硬件和运输操作对发育的影响。

拟设置以下分组：

（1）飞行早期暴露组：出生后较早阶段进入飞行任务，在空间飞行期间经历关键运动发育窗口。

（2）飞行较晚暴露组：出生后较晚阶段进入飞行任务，用于评估已经启动的运动发育过程对微重力的适应。

（3）同步地面对照组：在地面使用同样日龄、相近窝别和相同测试流程，模拟飞行组操作节律。

（4）普通饲养对照组：在标准动物房环境中饲养，不接受飞行硬件限制，用于评估笼具和操作因素。

公开资料中未提供完整样本量和性别比例。本训练样本保留该信息缺口，建议正式评审时要求申请方补充每组动物数量、雌雄比例、窝效应控制方式和剔除标准。

# 2、在轨实验方案

（1）动物饲养与健康监测。飞行期间维持母鼠和幼鼠基本饲养条件，记录动物存活、体重变化、母鼠照料行为和异常事件。由于幼鼠依赖母鼠照料，需特别记录母幼分离时间、测试操作对母鼠行为的影响，以及飞行环境对哺乳和幼鼠发育的一般影响。

（2）Animal Walking Apparatus 测试。AWA 内设置不同运动表面，包括网格表面、泡沫表面和不同直径水平杆。测试时将幼鼠置于起始位置，通过摄像系统记录其自发移动和通过测试表面的过程。每次测试控制持续时间，避免过度疲劳或母幼分离过长。视频记录应包含足够视角，用于后续盲法评分。

（3）行为指标采集。主要指标包括：从起点到终点的通过时间、停止次数、失足次数、抓握失败次数、身体翻转次数、前后肢协调程度、尾部和躯干姿势、表面探索行为和活动水平。对于无法完成测试的动物，记录失败原因，如不活动、持续翻滚、抓握不足或操作异常。

（4）飞行日志记录。记录每次测试日期、飞行任务日、动物日龄、测试表面、测试时长、操作者、设备状态、视频文件编号和异常说明。若出现摄像遮挡、照明不足、动物状态异常或设备故障，应标记对应片段为低质量数据。

# 3、地面对照实验方案

（1）同步地面对照。地面对照组按飞行组相同时间表进行 AWA 测试，使用等效设备和相同评分标准。温度、湿度、光照和喂养安排尽可能与飞行组一致。地面对照视频采用与飞行视频相同命名和质控规则。

（2）普通饲养对照。普通饲养组在标准笼具中饲养，仅在关键时间点接受行为测试。该组用于判断飞行硬件限制、测试操作和母幼分离对运动发育的影响。

（3）行为评分一致性。所有视频由至少两名评分者盲法评分。评分者不知道动物所属组别。若两名评分者对关键指标差异超过预设阈值，由第三名评分者复核。评分前需完成训练集视频一致性评估。

# 4、返回后检测方案

（1）急性行为测试。着陆后尽快开展水平杆行走、开放场活动、翻正反射和游泳测试。急性测试应记录着陆后时间间隔，因为动物可能在返回 1g 后快速适应，延迟测试可能低估飞行效应。

（2）恢复期行为测试。部分动物在返回后短期恢复，再次进行相同测试，用于判断飞行效应是否可逆。恢复期需记录饲养环境、体重变化、活动水平和一般健康状态。

（3）组织采集。根据实验终点安排，对动物进行灌流固定或组织快速取材。脊髓和脑组织用于形态学和免疫染色；骨骼肌用于肌纤维形态和成熟标志物分析。组织采集时间应与行为测试保持对应，避免测试造成额外应激影响组织结果。

（4）组织学检测。脊髓运动神经元可通过形态染色或神经元标志物定位，分析细胞体大小、树突分支和突触相关标志物。脑皮层检测运动相关区域的神经元形态和突触密度。骨骼肌检测肌纤维横截面积、肌肉成熟标志物和可能的萎缩相关标志物。

# 5、数据分析方案

行为数据以动物个体为基本单位，同时考虑窝别和母鼠效应。主要比较飞行组与同步地面对照组之间的差异，并使用普通饲养组解释硬件和操作因素。视频行为指标采用重复测量模型分析日龄、组别和测试表面的交互效应。组织学数据与行为指标进行相关分析，重点考察运动表现下降是否对应神经肌肉结构改变。

如果飞行样本量不足，应避免过度依赖显著性检验，重点报告效应方向、个体差异、置信区间和与地面对照的一致性。对于质量较差的视频片段，应明确剔除规则并报告剔除比例。

# 五、项目组织管理方案

# 1、项目组织管理体制

本项目由 NASA Neurolab 任务框架下的空间生命科学研究团队组织实施。项目分为动物实验组、飞行硬件组、行为学分析组和组织学分析组。动物实验组负责幼鼠分组、健康筛查、饲养流程和返地取材；飞行硬件组负责 Animal Walking Apparatus 的适配、摄像系统、在轨操作流程和数据保存；行为学分析组负责视频评分、行为测试和统计分析；组织学分析组负责脊髓、脑和肌肉样品制备及形态学分析。

公开资料中未给出完整项目负责人、团队成员职责和经费管理细节。正式评审时应要求申请方补充：项目 PI、动物实验责任人、飞行操作接口人、组织学平台负责人、数据管理负责人、伦理和动物福利责任人，以及各单位之间的任务边界。

# 2、项目运行管理机制

项目实行飞行任务节点管理。飞行前需完成动物实验方案审批、硬件安全评审、动物健康筛查、地面对照流程演练和评分标准冻结。飞行期间由地面团队根据任务日志和视频数据进行质量监控。返回后按照预先设定的时间表完成急性行为测试、恢复期测试和组织取材。所有原始视频、评分表、飞行日志、组织编号和分析脚本应统一归档，保证可追溯。

动物福利是本项目运行管理的核心约束。每次幼鼠测试应限制持续时间和母幼分离时间，避免因测试流程影响生长发育。若动物出现明显健康异常，应按预设标准终止测试并记录原因。

# 六、项目风险分析与控制

# 1、技术风险

（1）幼鼠饲养与母幼照料风险。出生后早期幼鼠依赖母鼠哺乳和照料，飞行环境、噪声、振动、操作干扰和微重力可能影响母鼠行为，进而间接影响幼鼠发育。控制措施：设置同步地面对照和普通饲养对照；记录母鼠照料行为；尽量缩短测试导致的母幼分离时间。

（2）视频数据质量风险。在轨空间有限，幼鼠运动速度和方向不可控，视频可能出现遮挡、焦点不足或角度不适合评分。控制措施：飞行前进行 AWA 视角验证；设置固定照明和背景；对每个测试片段记录质量等级；低质量视频不用于关键指标分析。

（3）样本量和窝效应风险。飞行任务动物数量有限，且同窝幼鼠之间并非完全独立。控制措施：统计模型中纳入窝别因素；报告个体层面数据；避免将同窝多只动物简单视为完全独立重复。

（4）返回后快速再适应风险。幼鼠返回 1g 环境后可能快速恢复部分行为，导致飞行效应被低估。控制措施：着陆后尽快完成急性测试；记录测试距着陆时间；设置恢复期测试区分急性效应和持续效应。

（5）行为指标解释风险。运动行为改变可能来自微重力、硬件限制、母幼照料变化、发射应激或发育延迟等多种因素。控制措施：设置多层对照；行为结果需结合体重、健康状态和组织学结果解释，不应单独归因。

# 2、安全与伦理风险

项目涉及哺乳动物幼体空间飞行实验，动物福利和伦理风险较高。风险包括母幼分离、飞行应激、测试疲劳、异常发育和返地取材。控制措施包括：飞行前完成动物实验伦理审批；设置明确的人道终点；限制测试时长和操作频次；确保饲养条件、温度、食物和水供应稳定；对所有异常死亡或健康事件进行记录和解释。

# 3、管理风险

项目依赖航天飞行任务窗口，若发射延期、返回延迟或硬件故障，可能影响动物日龄窗口和关键发育阶段。控制措施：预先设置备选日龄窗口；保留地面镜像实验；在统计分析中记录实际暴露时长和测试日龄；若关键窗口错过，应降低结论外推强度。
