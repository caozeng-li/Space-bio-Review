# 一、摘要（约 500 字）

我国载人航天即将步入新时代，航天员如何在长时间太空飞行中保持健康已成为国家重大需求。然而太空飞行会导致严重的肌肉质量与力量下降的肌萎缩，同时肌肉损伤发生的概率大幅提高，这对于宇航员执行太空任务带来很大的危险与挑战。而基于多分子层面的深入研究提示太空飞行会对表观遗传调控产生深远的影响，进而对重 器官特别是骨骼肌的功能产生危害。因此在太空真实环境下，开展空间微重力对骨骼肌再生能力的影响及其表观遗传机制研究，对于寻找对抗肌肉萎缩相应的措施，保障长期在轨航天员骨骼肌的正常功能，特别是损伤修复能力，提高工作效能，提供理论基础、实验证据和新的思路。拟研究内容包括：（1）微重力对骨骼肌干细胞（muscle stem cell，MuSC）功能的影响，揭示微重力影响骨骼肌再生的分子机制；（2）微重力对骨骼肌细胞中关键调控因子的液-液相分离（liquid-liquid phase separation，LLPS）现象的影响；（3）微重力环境下骨骼肌干细胞染色质三维结构变化规律进而推测微重力对表观调控的影响。预期成果：揭示空间微重力环境对骨骼肌再生能力的影响及其表观调控的变化，为航天飞行过程中肌肉萎缩防治措施研究提供新的思路。发表论文 2-3篇，申请专

# 二、主要指标

# 1、项目总目标

（1）发现空间微重力环境对骨骼肌干细胞功能（增殖、分化以及自我更新能力）的作用及机制。  
（2）揭示空间微重力环境对骨骼肌细胞功能相关的关键调控因子相分离现象的作用。  
（3）发现空间微重力环境下骨骼肌干细胞染色质三维结构的变化规律。

# 三、主要研究内容

# 1、 容包括以下几个方面

（1）研究微重力环境对 MuSC 功能的影响。

检测微重力环境下MuSC增殖，分化以及自我更新能力的变化，利用空间站现有的生物技术安全柜内细胞 模块中配置的明场，荧光及共聚焦显微镜来进行对MuSC分裂时长，分裂方向的进一步观察以及原位检测相关极性蛋白分布的变化来推测微重力影响MuSC功能的具体方式。该项目需 显微镜不低于20倍物镜分辨率不小于 $1 0 \mathrm { { u m } }$ ，目前在轨显微观察能力可以满足我们的需求。此外利用回收的样品进行转录 测序分析微重力对整体基因表达调控的影响。

（2）研究微重力环境对肌细胞中关键调控分子的液-液相分离形成的影响。

骨骼肌细胞中增强子活性与其功能密切相关，而调节超级增强子的转录蛋白可以通过形成局部的LLPS来行使转录调控功能,此外一些调控骨骼肌干细胞功能的关键转录因子也可以通过 LLPS来行驶转录功能。因此，通过监测微重力环境下这些因子的 LLPS形成变化探究微重力是否通过影响LLPS形成进而调控MuSC功能。

（3）研究微重力环境对骨骼肌干细胞中染色质三维结构的影响。

染色质相互作用对于基因调节和细胞功能非常重 超级增强子通过染色质环结构调控基因表达，而骨骼肌关键调控因子也可以协调特异性的3D基因 结构调控细胞功能。通过寻找微重力环境下骨骼肌干细胞染色质三维结构变化的规律来探究微重力影响 MuSC功能新的作用机制。目前在轨的显微镜最高可达1um应该可以满足该项目中对特定染色质三维结构观察的需求。

2、拟重点解决的科学问题或关键技术；

开展本项目研究将重点解决空间微重力是如何影响骨骼肌干细胞的功能，如何影响细胞内超级增强子活性以及染色质三维重塑，进而导致表观调控的变化，引发干细胞功能受损和肌萎缩的问题。

空间站实验实施过程中只能实现有限的人工参与，因此我们将利用空间站实验舱“生物技术实验柜”内的实验单元来完成细胞自动换液培养、实时观测（包括远程遥控）、样品固定、样品低温冻存和回收等实验过程，以保证细胞实验的顺利开展及结果的可靠性。而其中涉及的关键的技术包括：

（1）MuSC和单个肌纤维附着的MuSC的制备及长时间培养:获得稳定、可长期多次传代培养的 MuSC，是开展本项目空间实验研究的前提和关键技术之一。我们将利用转基因小鼠分离MuSC和单个肌纤维，并利用胡苹研究员发开的细胞培养方法将MuSC在体外长时间扩增培养并储存用于空间站培养的细胞材料筛选。

（2）空间细胞的实时观察：通过构建 Pax7-Cre-Cas9-GFP 转基因小鼠并分离获得带有GFP的MuSC；构建GFP融合的关键因子表达载体通过腺病毒感染获得表达GFP融合蛋白细胞株。利用生物技术实验柜内的细胞 模块中的荧光以及激光共聚焦显微镜 40倍以上物镜获得分辨率1um的 $1 0 2 4 ^ { * } 1 0 2 4$ 像素的图像来完成细胞成像以及实时观测。

# 3、研究中的创新点。

（1）本项目是率先开展空间飞行过程中骨骼肌干细胞增殖分化的调节作用研究，揭示骨骼肌干细胞感知和响应微重力环境的分子调控网络，对微重力环境下骨骼肌萎缩的发生机理有更全面的理解与认知，有望为空间骨骼肌的流失对抗措施研究提供新的策略。  
（2）本项目利用空间微重力环境，开展细胞内蛋白极性分布和分裂方式观察以及细胞内液-液相分离观察在国内外尚属首次。

# 四、研究方案

采用的研究方法和技术方案，包括地面研究/研制方案、在轨实验方案详述如下：

1、研究微重力环境对 MuSC 功能的影响。

为了在轨可以通过荧光来特异性示踪肌纤维上附着的不同肌肉干细胞亚群在地面我们首先将建立一种基于 Cre-LoxP同源重 酶介导的遗传谱系示踪系统获得两类tdTomato荧光标记的MuSC小鼠。分别通过流式分选以及单个肌纤维分离获得 MuSC，并通过荧光观察以及蛋白染色确定荧光示踪效率来评价其是否能满足后续实验需求。同时我们将在地面通过模拟体内的肌肉干细胞增殖条件，建立体外长期培养肌肉干细胞的系统，通过 RNA以及蛋白表达来评估MuSC增殖，分化以及自我更新能力。

在轨将设置2个微重力实验 ：骨骼肌干细胞 MuSC）和单个肌纤维附着的干细胞 Fiber）。每 设置6个培养单元。其中3个培养单元进行增殖培养，3个培养单元进行分化培养。细胞分别在轨培养7-10d（标准培养单元）。在轨期间定期换液，定期记录细胞密度，分裂时长以及观察 Fiber 裂方向。最后 1天，MuSC 4个培养单元添加固定液，收集固定的细胞；2个培养单元添加RNA保存液，收集RNA样品。Fiber 4个培养单元添加固定液，两个培养单元添加RNA保存液。地基对照 也做相应的处理。待样品返回地基后开展下述研究：对固定的MuSC以及肌纤维进行增殖、分化、自我更新标记物以及相关极性蛋白的免疫荧光染色检测以及 蛋白 H3K27ac 的 ChIP-seq 测序；对收集的 RNA 进行测序分析。在地面设计相应的实验对照 检测相应的指标，将结果与在轨实验的结果进行比较和分析。

2、研究微重力环境对肌细胞中关键调控分子的液-液相分离形成的影响。

首先在地面根据文献报道以及蛋白序列无序性预测筛选出可以

参与液相分离并与MuSC功能相关的蛋白。通过体外相分离实验证明其在 LLPS 中的可能作用。其次利用质粒过表达系统在体内证明该蛋白参与LLPS的形成，同时利用CRISPR-Cas9 基因编辑技术，构建内源表达该蛋白的GFP 融合蛋白细胞株，并通过荧光漂白实验实时观测蛋白的液-液相分离现象。之后利用该细胞株在轨观察LLPS的形成过程。

在轨设置2个微重力实验 ：一 是稳定表达与骨骼肌干细胞功能相关的GFP融合蛋白细胞株，设置两个培养单元；一 是稳定表达与超级增强子相关的 GFP 融合蛋白细胞株，设置两个培养单元。在轨期间对细胞进行荧光漂白实验并记录荧光恢复时间。同时将细胞添加固定液和储存液后返回地面进行相应的蛋白检测。在地面设计相应的实验对照 操作，将结果与在轨实验的结果进行比较和分析。

3、研究微重力环境对骨骼肌干细胞中染色质三维结构的影响。

在地面通过收集来自年轻与年老小鼠 MuSC进行染色质三维构象捕获技术（HiC）分析获得小鼠衰老过程中MuSC染色质三维结构变化规律，并针对显著变化的染色质结构域，设计不同荧光标签标记的先导RNA（gRNA），以及构建dCas9-EGFP融合蛋白细胞株，通过CRISPR-Liver FISH技术实时观察已知的染色质结构域变化。

在轨设置2个微重力实验 ：一 是利用 2个培养单元培养含有不同荧光标记 gRNA 的 dCas9-EGFP 融合蛋白细胞株，并通过CRISPR-Liver FISH技术实时观察已知的染色质结构域变化；一 是在微重力环境下正常培养的MuSC细胞株，设置6个培养单元。在轨期间进行细胞自动换液，2个培养单元细胞增殖培养7天后添加固定液；2个培养单元分化培养7天后添加固定液；2个培养单元先增殖培养五天后诱导分化五天添加固定液和 RNA储存液。显微镜实时拍摄荧光探针信号并记录之后添加固定液返回地面。待样品返回地

基后分别进行特定染色质结构分析，RNA测序以及染色质三维构想捕获技术分析。在地面设计相应的实验对照 操作，将结果与在轨实验的结果进行比较和分析。

# （1）空间细胞实验及样品保存

本项目是目前为止我国第一次在载人空间站上开展的骨骼肌干细胞的科学研究。因此，严格控制微重力环境中该细胞培养条件和样品回收保存条件是个挑战。考虑到我国前期利用飞行器已开展一些空间生命科学实验，无论在空间实验技术和实验装置的研发方面均积累了较丰富的经验。此外，本项目 之前参与过空间相关项目的匹配实验，在空间细胞实验技术、实验方案设计及实验流程方面

已积累丰富经验，为本项目的顺利开展奠定了良好基础，极大地降低了项目实施的风险。目前，尚无不可克服的技术难关，项目够按照载人空间站系统工程总体计划按期顺利完成相关研究任务。

# （2）样品在轨拍摄

本项目涉及到很多在轨细胞的显微拍摄实验，考虑到空间站现有的拍摄镜头的分辨率的限制，项目 地基前期实验，优化细胞内荧光蛋白或者分子探针的表达强度，确保利用现有的镜头可以捕捉到清晰的细胞图像，基于项目 站相关项目研究经验，样品在轨拍摄有风险但是该风险可控，通过优化蛋白或者分子探针表达系统能够达标并顺利完成在轨实验。

# （3）样品上下行

空间实验样品上行，受到一定的条件限制，可能不能立刻开展研究。因此，针对这个问题，我们将通过大量的地基前期实验，优化上行样品的细胞种类，接种浓度，培养条件等，确保在长时间后，依旧可以顺利完成在轨实验。空间实验样品下行过程中，有可能由于振动造成固定细胞脱附，此外由于温度保持等原因造成培养基、蛋白和RNA样品活性分子失活或降解。针对这些问题，本项目将在参考国内外生物样品下行方案的基础上，通过大量的地基前期实验，优化样品下行方案，以确保实验样品安全可靠的返回

# 七、经费预算与资源集成方案

本项目经费预算 2019年3月财政部正式颁发的《国防科研试制费管理办法》（财防[2019]18号文件）、中科院科研项目管理规定、中科院上海生科院相关管理办法、及其他空间站项目经费论证报告等进行编制。

本项目经费总计200万元。其中中科院前沿科学与教育局拟支持经费100万元，项目依托单位中国科学院上海营养与健康研究所匹配支持100万元。

该项目中研究、试制、鉴定、验收等全过程的各个环节（包括设计、计算、加工、检测、评测、试验等）中，由于自身条件限制，必须由外单位协助完成所发生的费用按外协合同或委托研制合同价格计入业务费用中的外协费。本项目外协费 包括用于专项试验所需的硬件的消耗费用，预算10万元。

此外，业务费用还包括针对项目围绕细胞生物样品开展的实验研究所需的材料费和测试化验加工费（ 涉及发射前细胞样品的构建、筛选、检测，特殊培养和诱导体系的建立，以及发射后细胞样品的回收和相关指标检测。所需 材料包括分子生物学及细胞生物学检测所需试剂，如培养基、血清、抗体、试剂盒、分子生物学试剂、细胞培养耗材以及测序费用），差旅、会议以及学术交流费用和项目产出的论文版面费和专利申请费。劳务费 于参与本项目的研究生以及临时人员劳务支出。奖励费是针对本项目产生的知识产权在项目执行期内进行应用和转化的，给予适当的鼓励和奖励。项目预算总表如下：
