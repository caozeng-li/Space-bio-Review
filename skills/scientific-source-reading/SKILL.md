# 按问题理解来源

从当前来源问题确定需要解释的原文关系。围绕指定来源及其附件，交付资料内的科学认识与依据，供持有申请的专题作者建立项目联系。

1. 先阅读本题已经打开的原文与原页，确定它们实际说明的对象和条件。需要扩展时，用 `acquire_source` 的 `navigation` 定位其他章节、表格或附件，再用 `browse_materials(pages, material_id)` 或 `read_materials` 阅读。需要搜索时，使用来源中的实际名称与所需条件，多条查询分别定位比较对象、方法或结果。检索命中只决定从哪里开始，阅读范围要覆盖决定答案的完整条件。
2. 沿原文的组织理解关系。实验研究连起对象、处理、比较和实际读出，定量结果连同比较基准、单位和时点解释；机制认识由干预、响应和对照建立。技术资料连起设备及部件、适用对象、条件、功能和使用阶段，参数与所在章节、表格行列及限定语一起阅读。同一来源中的不同实验或设备各自承担什么作用，按其实际关系说明。
3. PDF 原页随阅读文字一起交付时，直接结合原页理解行列、标签和值的关系；解析文字负责辅助定位。图形比较、轨迹、标尺和复杂版面以原页为阅读依据。需要细看某幅图时使用 `read_literature_visual`。原页自身存在缺项或排版矛盾时，说明它对本题哪项认识的影响，仍然使用其中明确的事实。
4. 直接回答委派问题，并解释决定答案的原文位置与关系。来源明确报道的观测或能力、原作者的解释和你据此提出的联系分别说明来由。若问题混用了对象，沿原文中的对象重新建立答案。已有材料足以形成明确的有限认识时交付；仍开放的连接说明它影响哪一部分回答。

正文直接回答问题，按实际对象组织认识。同一段或同一表行同时写清对象、条件、能力及决定这一认识的页码/表号，让接收者能沿这段说明找到对应原文。论文阅读使专题理解某项发现怎样成立；手册阅读使专题理解什么对象在什么条件下能完成什么操作或观测。来源能力为项目的可利用条件提供依据，申请是否安排了具体配置和时序由专题作者继续论证。
