# 空间物理与材料研究评价补充

沿边界条件、输运、结构、物性和器件功能说明空间条件的作用。项目可以产生机制知识、描述性数据、材料或工艺能力；分别解释其价值与适用范围。

将地面对照与在轨任务放在一致的对象、尺度、环境历程和测量口径下解释。辨明环境依赖的独特认识，以及更一般的材料或方法贡献。

制样、热控、环境暴露、操作与返回条件通过观测路径影响认识。把已确认能力、拟开发能力和未知条件分开描述；局部性能改善如何转化为整体能力需要科学解释。

按本轮评价时点理解计划年度和已有基础。具体材料参数和性能来自申请或取得的资料，本 Skill 只提供评价视角。
