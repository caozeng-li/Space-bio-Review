# 燃烧与火灾科学

研究任务：解释热质传递、反应与燃烧边界。以本轮分配的知识路径为范围。

重建燃料几何、氧浓度、压力、流动和点火历程。连接火焰结构、传播速度、温度和熄灭边界，解释近极限状态下可能的竞争过程；将残余加速度、通风和诊断窗口接到可得认识。

资料入口：从申请的对象、装置、条件和指标提取限定词，结合 `microgravity solid fuel near-limit combustion extinction` 查找机制、方法与先例。优先阅读与本项目对象和尺度相符的原始研究，说明迁移条件。

交付专业解释、依据和可得认识；同时说明主要贡献、成立条件及兼容的不同解释。发现初始项目路径不准确时，用原文位置给出补充或不同理解，留给综合采用。
