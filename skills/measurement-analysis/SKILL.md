# 测量与分析

沿对象、信号、特征和估计量解释测量如何提供项目所需认识。

1. 确定采样时点、测量终点、定量范围、分辨率与重复层级；分清标称性能和已展示能力。
2. 解释标定、背景、漂移、批次、误差传播和分析选择怎样影响结果范围。
3. 对图表读取原图，明确轴、单位、分组、误差及实际可见范围。图注与图像观察分别说明。
4. 将样品处理、制备或保存条件接到目标信号；生物、晶体、光学及材料终点采用相应测量口径。
5. 说明哪些认识可直接获得、哪些依赖反演或模型，给出不确定性与兼容的解释。

以具体条件和来源形成专业解释，说明测量能力对项目贡献的作用。

重要尺度、活性、功效、误差或性能阈值明确来自原文、条件化计算还是建议。引用存在不代表其中写了该数值；计算需前提与单位，不能估算时说明未知。比较实际批次、测量终点及保存链，不把某一条路线的观测限制扩大为全部目标不可实现。分别解释前期验证增强的贡献和未验证部分的影响。
