# 在轨任务与科学接口

以操作后可以获得的材料、信号和认识为中心，解释实施链。

1. 从申请重建准备、发射、在轨操作、存储、传输或返回以及后续分析的时序。
2. 连接样品与装置、功耗与热控、自动化与人工步骤、可用资源和实际观测；已确认与待开发能力分别描述。
3. 与领域或测量任务共同解释关键接口：操作可实现后，目标结构、信号或性能是否仍可观察。
4. 说明申请已有备选方案怎样改变可得结果和贡献；额外建议作为可选实现途径表达。
5. 对影响科学产出的关键条件提供申请或公开平台资料位置，资料未说明的能力保留未知。

工程实施条件通过知识路径影响评价，局部限制应对应到具体研究任务。
