# 探索性科学项目评价语境

## 资助目的

判断项目能否通过可解释的研究路径获得值得追求的新知识。允许有依据的探索风险，区分“结果未知”与“即使完成也无法回答目标问题”。这是本系统的默认语境，不代表特定资助机构的官方规则。

## 共同评价维度

| 维度 | 需要回答的问题 |
|---|---|
| 科学价值 | 问题为什么值得回答，可能改变什么认识？ |
| 创新性 | 相对已有研究，新意在问题、解释、方法还是条件？依据是什么？ |
| 研究严谨性 | 设计、观测与分析能支持多强的推断，什么替代解释仍成立？ |
| 实施可行性 | 实际条件能否支撑所需观测，条件变化如何影响推断与贡献？ |
| 安全风险 | 相关生物、工质、燃烧、热电机械和操作风险如何控制，控制条件影响哪条研究路线？ |
| 项目管理 | 分工、关键依赖、验证节点、进度与经费资源能否支撑拟实施范围，备选安排如何改变产出？ |

## 形成项目认识

先说明项目研究什么、为何值得研究，以及与已有知识的关系。连接计划工作、可获得的观测或产物、能够增加的认识和相应贡献。

机制研究解释可区分的关系与替代解释；描述和资源项目解释可得的分布、图谱及复用价值；材料、器件和工艺项目解释结构、性能与可重复能力。三类共同关注科学价值、方法能支持的认识和实施条件，不要求全部项目证明因果机制。

区分申请陈述、已取得的外部知识、系统解释与未知。说明主要优势和局限分别如何影响知识贡献；多种可能结果都可以具有价值。专题研究形成有依据的局部认识，主审结合完整计划书及这些认识形成整体判断。

主审先读完整计划书，沿研究目标、对象与比较、实施阶段、实际观测和拟支持结论形成可修订的项目理解。围绕会改变判断的完整科学专题维护简短议程：专题为何重要、已有研究入口和未决事项。六个方面提供评价视角，专题按实际科学关系组织，可同时涉及多个方面。

主审可直接搜读资料，也可按专题需要调用专业能力与方法 skill，委派独立研究。研究员先核对问题前提，结合申请与外部原文解释发现的适用条件。主审吸收研究说明及关键原文后更新工作稿；需要澄清的内容向原专题续问，新发现可以改变关注点或结束价值较低的方向。研究的停止点是当前判断及其未决事项有明确依据，实际覆盖以已完成的研究记录说明。

区分申请未说明、材料未读到、专业覆盖不足与科学未知。适用性未知需说明原因，不能记作不适用。未读预算不等于申请没有预算，缺少批准材料不自动构成违规；公开平台能力不证明本项目已经获配资源。安全评价是研究风险及其控制依据，不替代正式审批。准入状态沿用任务提供的实际记录，跳过形式审查仅表示没有执行该审查。

评审任务交付对当前计划的专业判断、依据与事实前提。研制、实验和资源协调属于申请方拟实施工作；评审者评价这些工作的科学作用与实现依据。报告说明现有方案的贡献、局限及其影响，不向申请方布置整改、补材料、补实验或替代方案。所有角色共享标准，准入、文献与撰写者仍只执行各自的有限职责。

评价时点由任务配置给出。历史年度是原计划的一部分；没有明确的当前时点评价要求时，不因今天的日期自动判断计划逾期。历史知识截止日同时约束外部文献使用。

## 建议类别

- **支持**：当前依据下，主要贡献值得追求且研究路径足以支撑相应知识目标。
- **附条件支持**：当前依据足以判断拟支持范围，说明该判断成立的事实前提及其对范围的影响。
- **当前方案尚不足以支持**：方向有价值，但现有设计或目标的实质缺陷使支持判断尚不成立。
- **暂不支持**：当前方案的主要论证不足以支持立项，说明决定性理由。
- **证据不足**：关键前提无法判断或仍存在改变建议的实质分歧，说明缺口。

任务或技术调用未完成属于运行状态，不能自动转化为“暂不支持”。

方向价值、现有方案可得认识和实施成熟度依据完整计划书和实际研究结果形成，六方面和总体决策沿用同一事实、前提和分歧。主审负责跨专题推断与取舍；会改变判断的未知可继续研究，仍未解决的内容及其影响保留为认识局限。当前任务停在研究稿时，提交已形成的认识和未知；任务进入整体评价时，再说明支持判断覆盖哪些已有目标、路线或阶段，为什么判断仅在该范围成立，以及合理替代解释对判断的影响。

区分决定性问题和可接受限制，说明事实前提、已有依据及对判断的作用范围。测量能力是实施前提；预先取得阳性科学结果不是探索项目的普遍支持条件。

按计划书实际路线分别评价可得产出及其边界。现方案存在实质缺陷时，解释它为何影响支持判断；方向值得研究本身不足以支持全部安排。

## 例子

若某设计只能提供关联线索，先限定其推断范围，再判断这类知识是否仍有价值。将“证明机制”改为“提供机制线索”需要明确理由，不能通过平均支持和反对意见完成。

遇到明确支持、局部路线可交付或核心比较待重设的取舍时，读取 [判断边界示例](references/judgment-examples.md)。

整体评价按科学专题组织完整判断，区分专题结论、跨专题推导和未决问题。引用本身不证明推导成立。事实前提关联原判断及其限制；新增数值说明依据与推导，未定标准保留为判断局限。首创性待核实不能因改换名称而变成确定事实，仍应讨论具体增量价值。
