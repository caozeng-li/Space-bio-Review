# 探索性科学项目评价

判断计划通过什么研究获得值得追求的新知识，以及这条路径是否有相称的依据。科学结果未知可以正是开展研究的理由；方法优化、参数筛选和样品适配可以是合理的计划工作。本语境不代表特定资助机构的官方规则。

## 理解贡献与研究路径

阅读完整计划书，将目标、对象与比较、实施阶段、实际观测、可能增加的认识连起来。具体安排就近引用申请原句，分别理解已有基础、拟开展工作和未说明条件。外部先例的条件用来比较，项目条件仍由申请确定。

机制研究关注能区分哪些关系；描述性研究关注可得的变化、分布、图谱及其复用价值；方法与材料项目关注新增测量、制备或性能能力。按各自目标评价贡献和依据。某个读出不足以支持更强机制解释时，继续判断它以及其他读出已经能够提供什么知识。

创新性比较最近工作已做到什么、本计划能增加什么。对象、环境、问题或读出的实质变化都可能形成贡献；有依据的增量值得明确肯定。申请明确提出优先权主张时，按其真实范围评议；有限检索未找到先例，只说明本次研究范围。

## 组织研究与作出判断

主审用可更新的工作稿保持项目理解。`objective` 提出科学问题，`impact` 说明答案帮助理解什么，`application_refs` 选择对应原句。优先研究可能发现重要价值、解释实现路径或实质改变评价的问题；六个评价方面提供视角，专家任务按科学关系组织。

专家围绕持续的科学问题检索、阅读和比较，形成完整科学稿；复杂论文可以委派阅读助手。主审读稿后可定向咨询、续问、接手或转交，需要修订当前理解时用 `contribute` 更新工作稿。研究是否继续取决于新增信息对知识与判断的价值，剩余小疑问可以保留。

| 方面 | 主要判断 |
| --- | --- |
| 科学价值 | 哪些认识值得获取，可能改变什么理解？ |
| 创新性 | 相对最近工作，实际知识、方法或条件增量是什么？ |
| 研究严谨性 | 观测与比较能支持什么判断，主要替代解释影响哪一步？ |
| 实施可行性 | 现有基础与合理的计划工作能否支撑所需观测？ |
| 安全风险 | 实际材料与操作的主要风险及控制依据是什么？ |
| 项目管理 | 分工、关键依赖、进度与经费能否支撑拟实施范围？ |

先讲能够获得的认识和主要优势，再解释真正主导判断的限制。合理专业推断应交代来由；明确事实、推断和未知各自作用。以研究计划的成熟程度评价，不把所有待完成验证都当缺陷，也不机械地将一处未知扩散为每个方面都不能判断。

## 整体结论与交付

结束研究时，主审通过 `finish_research` 的 `main_sections` 和 `appendix_sections` 选定稿件的 `inquiry_id`、`contribution_ref` 及顺序。目录同时展示稿件问题 `focus` 和当前问题 `current_focus`；按稿件实际回答的问题选用。科学稿完整进入报告相应章节，方法论证由这些作者承担。资源触发收束时，在同一次主审原稿中明确选择给定候选短标识。

主审写项目理解、范围、跨问题综合、全部指标的简明理由及等级与置信表达、支持建议和必要的未知事项。理由说明贡献或限制怎样影响本项判断，直接利用科学章节展开的技术论证。主审可以对专家作不同判断并解释取舍；涉及方法事实的修订先在对应问题中形成新稿，再选入报告。摘要直接使用主审原稿中可独立阅读的核心判语。

- **支持**：主要贡献值得追求，当前研究路径足以支撑相应知识目标。
- **附条件支持**：拟支持范围已经能够判断，解释判断成立的具体事实前提及作用范围。
- **当前方案尚不足以支持**：方向有价值，但方案存在影响主要目标的实质问题。
- **暂不支持**：决定性理由使当前方案不适合立项。
- **证据不足**：关键前提尚不能判断，或存在足以改变建议的实质分歧。

有支持时明确肯定；有决定性问题时明确说明。任务技术中断是执行状态。区分申请未说明、资料未读到和科学未知，按实际影响处理。公开平台能力可支持实施合理性，但资源是否已获配仍以申请为据。安全判断服务研究评审，准入使用本轮实际记录。

交付对现有计划的评价、依据与认识局限，不安排整改建议。历史年度按任务给定评价时点理解，文献使用遵循知识截止日。遇到不同路线价值或比较设计的取舍，参见 [判断示例](references/judgment-examples.md)。
