# 探索性科学项目评价语境

## 资助目的

判断项目能否通过可解释的研究路径获得值得追求的新知识。允许有依据的探索风险，区分“结果未知”与“即使完成也无法回答目标问题”。这是本系统的默认语境，不代表特定资助机构的官方规则。

## 共同评价维度

| 维度 | 需要回答的问题 |
|---|---|
| 科学价值 | 问题为什么值得回答，可能改变什么认识？ |
| 创新性 | 相对已有研究，新意在问题、解释、方法还是条件？依据是什么？ |
| 研究严谨性 | 设计、观测与分析能支持多强的推断，什么替代解释仍成立？ |
| 实施可行性 | 实际条件能否支撑所需观测，条件变化如何影响推断与贡献？ |
| 安全风险 | 相关生物、工质、燃烧、热电机械和操作风险如何控制，控制条件影响哪条研究路线？ |
| 项目管理 | 分工、关键依赖、验证节点、进度与经费资源能否支撑拟实施范围，备选安排如何改变产出？ |

## 形成项目认识

先说明项目研究什么、为何值得研究，以及与已有知识的关系。连接计划工作、可获得的观测或产物、能够增加的认识和相应贡献。

机制研究解释可区分的关系与替代解释；描述和资源项目解释可得的分布、图谱及复用价值；材料、器件和工艺项目解释结构、性能与可重复能力。三类共同关注科学价值、方法能支持的认识和实施条件，不要求全部项目证明因果机制。

区分申请陈述、已取得的外部知识、系统解释与未知。说明主要优势和局限分别如何影响知识贡献；多种可能结果都可以具有价值。专业研究先完成局部认识，整体建议由综合产生。

六个方面作为问题的覆盖视角，可由同一领域专家结合方法承担。问题生成者统一形成题单；专家围绕已分配问题直接阅读方案，纠正题目前提并说明跨专业关系。题外范围及未解决信息保留为科学局限，供综合说明实际覆盖。适用性未知需说明原因，不能记作不适用。区分申请未说明、材料未读到、专业覆盖不足与科学未知。未读预算不等于申请没有预算，缺少批准材料不自动构成违规；公开平台能力不证明本项目已经获配资源。安全评价是研究风险及其控制依据，不替代正式审批。

评审任务交付专业判断、依据与条件。研制、实验和资源协调属于申请方拟实施工作；评审者评价这些工作的科学作用与实现依据。所有角色共享标准，准入、文献与撰写者仍只执行各自的有限职责。

评价时点由任务配置给出。历史年度是原计划的一部分；没有明确的当前时点评价要求时，不因今天的日期自动判断计划逾期。历史知识截止日同时约束外部文献使用。

## 建议类别

- **支持**：当前依据下，主要贡献值得追求且研究路径足以支撑相应知识目标。
- **附条件支持**：当前依据足以判断拟支持范围，剩余条件可在明确节点验证或落实；说明条件及未满足时的范围调整。
- **修改后再评**：需要实质修订设计或目标后才能重新判断。
- **暂不支持**：当前方案的主要论证不足以支持立项，说明决定性理由。
- **证据不足**：关键前提无法判断或仍存在改变建议的实质分歧，说明缺口。

任务或技术调用未完成属于运行状态，不能自动转化为“暂不支持”。

方向价值、现有方案可得认识和实施成熟度依据共享的问题研究结果形成，六方面和总体决策沿用同一结论、条件和分歧。综合负责跨问题推断与取舍；缺少的新事实及其影响作为未决条件保留，不启动新题或补充派工。指出建议覆盖哪些目标、路线或阶段，为什么选择这一范围，以及如何处理可能改变建议的合理替代解释。

重要条件区分决定性问题、可接受限制和可选改进，说明作用范围、可接受证据、解决时点与未满足后果。验证测量能力是实施前提；预先取得阳性科学结果不是探索项目的普遍支持条件。具体实现举例保留可替代性。

按项目实际讨论有意义的替代方案，无须固定数量；分阶段支持须有适用机制依据或明确作为条件化选择。现方案仍需实质改造时，解释为何要先修订后判断，不能仅凭方向值得研究就支持全部安排。

## 例子

若某设计只能提供关联线索，先限定其推断范围，再判断这类知识是否仍有价值。将“证明机制”改为“提供机制线索”需要明确理由，不能通过平均支持和反对意见完成。

遇到明确支持、局部路线可交付或核心比较待重设的取舍时，读取 [判断边界示例](references/judgment-examples.md)。

综合按具体问题组织完整原判断，区分继承、新推导和未决问题。引用本身不证明推导成立。条件关联原判断及其限制；新增数值说明依据、推导或建议性质，未定标准保留待论证。首创性待核实不能因改换名称而变成确定事实，仍应讨论具体增量价值。
