# 中 华 人 民 共 和 国 国 家 标 准

GB/T28877—2012

# 空间科学实验通用要求

# Generalrequirementsforspacescienceexperiments

2012-11-05发布

2013-02-15实施

## 前 言

本标准按照 / — 给出的规则起草。

本标准由全国空间科学及应用标准化技术委员会( / )归口。

本标准起草单位:中国科学院空间应用工程与技术中心、中国科学院生物物理研究所、中国科学院金属研究所、中国科学院力学研究所。

本标准主要起草人:郭炯、张玉涵、仓怀兴、罗兴宏、康崎。

## 引 言

地球外层空间为科学研究提供了地面难以获得的特殊实验条件。由于空间实验代价高、风险大、机会少 对开展空间科学实验形成了约束 同时 在空间进行科学实验应该满足安全性和可靠性要求 不仅要保证空间科学实验装置正常工作,还应避免对空间飞行器和其他系统产生影响与危害。规范在空间飞行器上开展的科学实验,是十分必要的。

本标准通过提出在空间开展科学实验的一般性要求,规范空间科学实验各参与方在开展实验时的活动。

# 空间科学实验通用要求

## 1 范围

本标准规定了在空间飞行器上进行的空间科学实验项目全过程中应满足的通用要求。

本标准适用于利用卫星、飞船、空间实验室、空间站等各类空间飞行器开展的科学实验研究活动。利用探空火箭、高空气球等其他飞行器以及在其他天体上开展的科学实验研究活动可参考使用本标准。

## 2 术语和定义

下列术语和定义适用于本文件。

## 21

## 空间科学实验 spacescienceexperiment

利用空间条件开展的科学研究活动。

注1 本标准中的空间科学实验领域主要包括空间 微重力 流体物理和燃烧科学 空间材料科学 空间基础物理 空间生命科学和生物技术的实验研究等

注2:空间条件主要指微重力环境、真空、超净、辐射环境以及在空间飞行器上的人造环境中一种条件或多种条件的组合。

## 2.2

## 空间科学实验项目 spacescienceexperimentalproject

经过立项过程确定的空间科学实验任务 是在一定时间内围绕完成空间科学实验目标开展的相关工作的总称。

注 本标准中在不发生歧义的情况下 简称项目

## 2.3

## 空间科学实验装置 spacescienceexperimentalsystem

满足空间科学实验需求的设备或实验系统

注:本标准中在不发生歧义的情况下,简称实验装置。

## 2.4

## 项目管理方 projectmanagement

对科学实验项目立项、实施、验收等进行组织、监督和协调的团体。

## 2.5

## 项目建议方 projectproposer

提出科学问题,要求开展相应空间科学实验和研究的个人或团体。

注 项目建议方一般为项目建议书提出者 在项目立项后还应对项目最终结果负责

## 26

## 科学研究方 scientificresearcher

围绕项目的科学问题 开展研究的个人或团体

注 科学研究方可以为项目建议方和 或 参与相关科学基础研究的个人或团体

## 2.7

## 实验装置研制方 experimentfacilitydeveloper

为项目实施,研制实验装置的个人或团体。

## 3 管理体系和阶段划分

## 31 管理体系

空间科学实验项目的管理应以项目管理方为主,由项目管理方、项目建议方和实验装置研制方组成分级管理体系。

空间科学实验项目管理体系应能满足科学需求和相应工程任务的管理要求。

## 32 阶段划分

空间科学实验项目宜与工程计划同步安排实施,亦可根据项目具体情况安排实施。原则上应覆盖四个阶段 立项阶段 地面研究及研制阶段 空间实验阶段 处理分析阶段

## 4 立项阶段

## 4.1 工作目标

立项阶段的工作目标是评估空间科学实验项目实施的必要性和可行性 实现立项 项目建议方应提供足够证据说明项目的必要性与可行性 项目管理方应按必要的程序组织评审和进行确认

## 42 工作内容与要求

## 4.2.1 立项准备

项目建议方(或项目建议方联合实验装置研制方)应说明项目的科学实验(或实验技术)的目标和意义 提供基本输入信息 编写项目建议书 参加项目评审

项目管理方应组织项目征集和项目立项评审 协调实验资源需求 制定实施计划和明确任务分工

## 4.2.2 项目建议要求

项目建议方应研究以下方面的内容:

) 在对学科领域发展趋势进行充分调研、分析的基础上,应明确提出项目的科学实验(或实验技术 的目标和意义 阐明实验内容 实验原理 拟解决的科学 或技术 问题 及其在本学科 本领域内的前沿性和创新性、可能产生的影响和效益。

) 通过项目管理方了解空间飞行器的基本情况,初步规划并提出开展空间科学实验项目的基本需求 包括

空间飞行器的环境条件 如微重力水平 真空度 温度 辐照条件等

) 资源需求:如重量和尺寸、能源需求、测控和数据传输需求等;

) 空间科学实验装置所需的(有人或无人)在轨维护、操作和运行模式、发射和回收的要求等。

## 423 编写和提交项目建议书

编写项目建议书应遵循以下要求:

项目建议方按照项目管理方提供的提纲编写项目建议书

) 项目建议书基本内容包括:

基本信息 实验名称 项目建议方负责人姓名 所在单位 现有工作基础和保障条件 预期成果 合作单位及队伍 研制周期及经费预算

主要内容 项目的科学目的和意义 创新性 必要性 先进性 可行性和拟解决的科学 或技术)问题;实验内容、实验原理、实验方案和技术路线、关键技术、可行性和风险分析等。

) 项目建议书编制完成后,向项目管理方正式提交相关文档,申请进行项目的立项评审。

## 424 评审和立项

项目管理方应组织专家对项目建议方提出的项目建议书及相关材料进行科学和技术评审。科学评审由本领域的学科专家为主进行,技术评审由学科专家和工程技术专家共同进行。评审通过后,由任务主管部门批复立项,签订合同或下达任务书。

## 425 地面研究及研制阶段的工作准备

项目正式立项后,项目建议方按照具体工程型号的要求,开始为项目在下一阶段(地面研究及研制阶段)做好工作准备,应进行技术条件准备和计划安排的全面策划:

) 规划项目科学研究团队、实验装置研制团队(规划时应列出空间科学实验参与人员名单及其在各阶段的基本职责),以及开展科学研究、实验样品制备(含辅助材料等)和实验装置研制所需设施设备和工作条件;

) 提出项目的实验方案、技术路线、初步研制计划和流程、大型试验项目安排;

提出实验装置 仪器 地面研究支持设施和实验对象等设计 制造 试验的规划 以及实验装置的功能要求和性能指标;

制定空间科学实验研究的地面支持设施的使用计划和技术要求

) 提出实验装置与空间飞行器初步机、电、热的接口;

) 提出保障空间科学实验任务实施所要求的平台能力,如对能源支持能力、数据处理和传输能力 正常的在轨运行和维护能力 航天员操作能力等的要求

) 提出对支持空间科学实验的空间飞行器运行参数的需求;

) 实验装置安装在空间飞行器上可能产生的其他特殊要求,如空间飞行器结构或实验装置、实验对象等所包含的结构材料 物理性实验对象和实验介质等的出气 释热或吸热 以及其他气 液等物理接口和生物 化学相容性等问题

) 对发射场地和回收场地以及对发射过程和回收过程的要求;

) 实验数据或样品的处理办法;

) 后续研究方案、实验结果的验证和成果的评估办法等。

## 5 地面研究及研制阶段

## 51 工作目标

地面研究及研制阶段的工作目标是研制出满足空间科学实验需求 质量和可靠性达到任务规定要求的实验装置;选择和优化实验对象,完成空间科学实验与实验装置配合的地面试验验证;为实施空间科学实验做好科学与技术准备。

## 52 工作内容与要求

## 521 实验方案设计

在立项阶段形成的项目策划基础上 设计实验方案 开展围绕空间科学实验方案的地基理论研究和实验仿真研究 并据此开展科学实验工作与装置研制和试验 并为空间实验阶段做好准备工作

## 522 科学实验工作

## 5221 科学实验手段

研究并提出为实施空间科学实验所需要的天地技术装置和支持设施 设备 包括软硬件设备和部件,以及空间科学实验期间的信息收集和数据记录设备等的要求。制定实验装置的设计方案,确定实验系统的结构特性、电子学特性、热特性以及设计参数等,开展实验装置的研制。

## 5.2.2.2 科学实验对象

根据实验方案,提出科学实验样品、介质和实验参数,并通过地面实验筛选、优化最终确定。

## 5223 实验方案的优化

解决科学实验对象与实验装置研制过程中的关键科学和技术问题 优化实验方案 优化实验方案应依据实验需求、材料相容性试验、实验装置和实验系统的匹配试验等地面试验进行。

## 5224 地面试验验证

依据项目立项时的策划 配合实验装置的研发 开展本阶段需要进行的各类测试试验 对各项试验应有具体策划,提出试验目的、操作要求。地面验证性试验应编制测试大纲和测试细则。

## 5225 地面对比实验

当需要进行地面对比实验时 需提出地面实验方案和细则 实验技术要求 环境条件和操作规范

## 5226 实验结果处理

空间科学实验和地面对比实验中获得的数据或样品的特性和处理步骤 如果有实验样品回收 包括对样品的分解和处置办法)、传送数据的格式要求、传送样品的步骤、准备科学实验结果分析报告的步骤和时间节点。

## 5227 中期评估

在项目进行到适当时机时 项目管理方应组织进行项目的中期评估 中期评估的目的是通过已经进行的地面试验验证结果 评估项目实施的有效性和项目继续实施中需要优化的工作内容

根据中期评估结果开展后续科学实验工作。

## 5.2.2.8 科学实验评审

按工程研制节点安排组织对空间科学实验进行评审 确定科学实验方案和实验样品状态 提交工程各阶段有关科学实验的计划、质量和技术的全部文件。

## 523 实验装置研制和试验

实验装置研制方应根据具体工程型号的管理要求和科学实验工作的安排 进行实验装置的研制和试验 并为科学研究方提供技术支持服务 主要工作内容包括

研究空间科学实验需求和工程实现要求 设计研制实验装置或选择已有设备

) 并行研发或选配相关辅助设备和必要的备份件、配套件和工具等;

以空间飞行器环境试验条件为依据 按照实施空间科学实验时的真实环境条件 进行实验样品和材料层次以及整机系统级的可靠性试验

d) 配合科学研究方开展地基验证性研究和试验 包括进行空间科学实验的实验样品等与系统结构材料的相容性 匹配性 系统性和操作性试验等

以实验装置研制方为主 科学研究方参与 按项目管理方的工程进度与质量管理要求 实施全程管理;

) 所有实验装置被提供给空间科学实验操作人员时,应有必要的服务指导和操作手册;

g) 按工程研制节点交付实验装置产品(含实验样品),安排提交工程各阶段要求项目准备的相关文件。

## 524 空间实验阶段准备

项目管理方应组织科学研究方和实验装置研制方为空间实验阶段做好下列准备工作:

) 通过系统间协调和试验验证,制定飞行控制程序,包括:

) 实验进程与控制需求以及控制方式;

) 实验进程控制条件及判据;

) 实验进程的控制影响及科学数据收集;

) 实验进程逻辑时序关系与约束;

) 实施进程操作的程序步骤。

制定空间实验阶段地面和空间实验实施方案

) 制定数据处理、天地实验对比、实验结果分析等流程,并形成文件。

) 分析在轨运行的故障模式,制定处理预案。

制定发射工作方案 包括 实验装置临场检测 实验样品制备 保存 运输等 制定发射场流程性演练的计划。

) 研究在轨运行的数据和样品分析方法及技术措施。

) 确认项目在轨运行的安全性。

) 研究空间实验后期样品、数据处理与分析方法,制定回收场样品回收实施方案、技术流程和转运实施方案。

) 落实发射场、回收场、地面对比实验室、测控管理中心的技术支持要求,包括设备、环境、水、气等资源配置需求和保障条件

) 需要时,对航天员进行培训。

) 制定后续研究计划。

) 必要时,组织地面模拟飞行试验。

)由项目各参与方共同组成在发射场、飞行控制中心和回收场的工作组织。

## 6 空间实验阶段

## 61 工作目标

完成空间科学实验,获得实验数据和结果,进行空间科学实验研究的分析工作,取得科学结果。

## 62 工作内容与要求

## 621 发射前准备工作

项目各参与方应预先制定发射场工作流程,主要工作内容包括:

) 实验装置研制方配合空间飞行器开展发射场测试,确定实验装置发射前技术状态;

科学研究方提供并确认空间实验对象的最终技术状态及空间实验流程

实验装置研制方和科学研究方配合完成实验对象 实验样品等 的加注 加载 检测等工作 必要时可安排演练试验来协调 优化空间实验的发射前工作流程

) 完成实验装置临射前在空间飞行器上的安装。

## 622 在轨实验

项目各参与方应按照飞行控制技术计划实施空间实验 包括) 按照空间实验流程进行实验进程控制与监测,实验科学数据的收集和分析,以及实验状态判读;

) 对下传的数据或图像进行初步分析;

) 自动或人工记录实验进程中的实验条件;

) 如果是空间有人操作的实验模式,科学研究方(或实验装置研制方)承担空间实验操作的地面指导;

) 必要时,由实验装置研制方和科学研究方共同配合完成地面对比实验的监控管理与实时操作;

) 当出现偏差时,按照事先编制的处理预案处理;出现预案外的偏差时,进行临场决策处理;

) 实验进程出现故障时,进行故障应急状态分析,并提出处置建议;

) 向相关方通报实验情况。

## 623 地面实验

作为实验方案内容之一 在需要分离空间实验环境影响因素时 可安排天地对比实验 实验方式可根据项目实验特点和科学研究需要,以及对比所需提取的实验条件要素来决定。

## 624 回收场工作

需要回收实验样品或实验装置的空间科学实验项目应按制定的回收场样品回收实施方案 技术流程和转运实施方案进行回收:

) 按技术流程完成实验样品和(或)实验装置的回收和初步处置;

) 按转运方案将样品和(或)实验装置运至指定地点移交给科学研究方;

) 记录回收、转运过程中的环境条件。

## 625 在轨实验结束后的工作

在轨实验结束 获得实验样品和 或 实验数据后 进行技术总结和科学实验初步总结 制定处理分析阶段的工作方案 其中 技术总结应按照具体工程型号要求和科学实验工作需求进行 科学实验初步总结应包括以下内容:

) 空间科学实验进程;

获得的实验样品或实验数据 实验工程数据

) 实验装置运行状态对实验的影响;

适用时 航天员参与实验时的操作评价和影响

) 初步科学结果及发现的问题;

继续开展下阶段工作的情况评估

## 7 处理分析阶段

科学实验结果处理分析阶段的主要工作内容包括

开展获取空间科学实验结果 实验样品 实验数据 工程数据 的科学分析工作

) 编制空间科学实验总结报告;

项目管理方应组织项目验收和结题评审 对项目立项时的科学实验目标完成情况进行评价 给出明确结论。
