# 空间细胞样品返回储存可用性先导（合成接入案例）

目标：确认一种已经选定的细胞固定流程能否为后续空间细胞形态研究提供可分析图像，本期不识别微重力机制。

设计：同批成纤维细胞随机分至三个在轨培养盒、三个地面流程对照盒；培养盒是独立重复。两组在同一时间点用同批固定液固定；地面组匹配飞行温度记录和加液时间。载荷已承诺提供温控、固定和返回运输接口。

观测：返回后统一盲法成像，逐盒报告可分割细胞比例、信噪比和不确定区间。所有失败样品计入，不以单细胞数充当重复数，不用组间差异证明微重力效应。

关键未知：返回前预计存储14天，但该固定方案在此时长下的荧光稳定性尚未验证。若衰减，低质量图像可能来自存储而非在轨培养。申请可接受先完成匹配存储条件的地面预验证再执行飞行，预验证目前尚未完成。

贡献范围：形成此细胞、固定与储存条件下的流程可用性依据，为是否值得开展下一期机制研究提供判断。经费和舱位已落实，本期无新增硬件开发。
